- 凭据只从工作区外显式指定的服务器信息文件读入当前测试子进程环境变量；未写入源码、测试产物、报告、截图或命令输出。

- 隧道只使用回环地址与运行时分配的临时端口。

## 使用者视角发现与修复

### 慢速服务器刷新会吞掉“新建文件/文件夹”输入行

真实 VPS 往返比本地夹具慢。用户在 SFTP 面板点击新建后，如果后台延迟刷新恰好返回，旧逻辑会用服务器列表整体替换本地列表，尚无远端 ID 的编辑草稿随即消失，表现为输入框突然被关闭。

修复后，后台刷新会保留 `isEditing` 且尚无 ID 的临时行，同时仍以服务器返回值更新已提交条目，并基于合并后的列表校正选中项和文件树。提交或取消后的行不会被错误保留。针对性单元测试 8 项加外部验收卫生测试 2 项，共 10/10 通过；真实综合流程没有再出现输入行消失。

### 长流程中的远程编辑确认等待不稳定

远程编辑保存会先建立恢复点并读取变更预览；在长会话和慢速服务器上，这一步可能超过原测试的 30 秒等待。独立最小用例证明产品安全确认、远端写入、回读和权限链路正常。测试随后改为从当前可见文本框锁定其编辑弹窗、点击该弹窗首个主按钮，并为安全预览保留 60 秒等待。独立编辑 1/1 与完整综合场景均通过。

### 外部验收隔离配置缺少已信任主机密钥

质量测试使用隔离用户目录，原环境没有 `known_hosts`，导致应用路径与直接 SSH 校验路径不一致。验收启动器现在只复制当前目标主机匹配的公钥记录到临时配置目录，不复制其他主机信息；产品仍执行严格主机密钥校验，不关闭校验或自动信任未知密钥。

### 超长列表中的拖拽目标不可见

首次完整旅程在创建较多远端条目后，上传目标位于滚动区域外，鼠标测试无法取得目标坐标。独立拖拽用例证明产品行为正常；综合旅程现在先将明确目标滚动到可见区域并验证可见，再执行与用户一致的拖拽。
