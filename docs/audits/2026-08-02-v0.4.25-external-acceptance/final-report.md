# ShellPilot v0.4.25 外部环境三轮自检与 v0.4.26 发布报告

## 范围与安全边界

本轮以已发布 v0.4.25 为基线，使用用户授权的 SSH/SFTP 服务器补齐此前六项外部环境验收。服务器凭据只通过进程环境变量传入，不写入仓库、报告、日志或截图。远端写操作仅限随机 `/tmp/.shellpilot-*` 沙箱；隧道仅使用回环地址和临时端口。未修改、重启或重载 x-ui、sshd、防火墙、容器、数据库、业务目录或其他已安装服务。

## 第一轮：真实连接态 SFTP 用户旅程

以普通用户操作顺序完成双栏导航、地址跳转、父目录、刷新、排序、筛选、多选、右键菜单、拖拽、键盘复制/粘贴/删除、冲突重命名、创建目录、跨目录移动、上传、下载、远端文本编辑与权限修改。

发现并修复两项生产缺陷：

1. 部分 SFTP 服务的 `stat` 不返回设备编号，旧实现把不同父目录直接当成跨文件系统，导致合法拖拽移动被拒绝。现在只有两侧设备编号都存在且不同时才拒绝，同端移动使用原子 SFTP `rename`。
2. 文本保存确认摘要错误调用翻译格式化函数，React 在渲染对象子节点时失败，确认 Promise 永不结束。修正参数后，变更预览、确认、远端写入和重新读取均通过。

结果：SFTP-01、SFTP-02、SFTP-13 从“部分满足”关闭为“已满足”。

## 第二轮：真实隧道与失败路径

通过桌面隧道管理器完成：

- 远程转发：VPS 回环监听连接到本机临时 responder，并返回随机标记。
- SOCKS5：本机临时代理完成原始 SOCKS5 握手，并通过代理读取 VPS `127.0.0.1:22` 的 SSH banner。
- 目标拒绝：本地转发指向 VPS 未监听的回环端口，界面显示 `SSH_TUNNEL_DESTINATION_REFUSED` 和可执行中文建议。
- 生命周期：所有测试隧道均由界面停止，临时 listener 均关闭。

同时修复运行后隧道失败只写日志、用户界面缺少稳定错误码和建议的问题。服务器当前允许转发；为遵守“不改变现有服务”的约束，没有通过修改 sshd 策略制造 `administratively prohibited`。该子场景继续由运行时/UI 契约覆盖，TUN-06 因缺少独立禁止转发端点仍为“部分满足”。TUN-01 已关闭为“已满足”。

## 第三轮：完整重放、清理与需求复核

外部验收文件在单 worker 下串行重放，避免并发 SSH 会话影响共享服务器。完整 SFTP 主流程、编辑/权限/删除、独立拖拽上传、远程转发/SOCKS5/目标拒绝共 4/4 通过；随后通过应用自身已认证的 SFTP 会话只读检查 `/tmp`，确认没有 `.shellpilot-e2e-*` 残留。

一次重放暴露了验收脚本竞态：拖拽后“传输队列当前为空”可能发生在异步入队前。断言已改为轮询目标路径真实 `lstat`，因此产品传输失败仍会被准确报告。

需求矩阵当前为：163 项已满足、2 项部分满足、1 项已废止、0 项未满足、0 项未验证。剩余两项是：

1. TUN-06 的服务器策略禁止转发实机子场景；需要专用禁转发 SSH 端点，不能在共享 VPS 上改 sshd 制造。
2. REL-13 的正式官网一致性；仓库只有设计稿，没有独立官网部署，且本轮未获授权改变 VPS 现有 Web 服务。
