# ShellPilot v0.4.22 Comprehensive Self-Audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 修复 v0.4.22 已确认缺陷，并按真实用户路径完成 AI 配置、对话、内容输入、Agent 工具、恢复与交接能力的分层自检和完善。

**Architecture:** 保持现有 Renderer → IPC → 主进程 → 模型/Agent 网关边界不变，以单元契约、隔离 Electron E2E、最小真实模型调用和真实 VPS 只读测试逐层验证。修复仅落在可复现根因处：附件路由与 Office 预检、结构化导出、兼容依赖补丁，以及后续审计中有明确红—绿证据的行为。

**Tech Stack:** Electron 41、React 19、Ant Design 6、Node.js test runner、JSZip、ExcelJS、npm overrides。
