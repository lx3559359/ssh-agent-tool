# 成果物、故障档案与 AI 内容读取设计

## 目标

在不改变 SSH、SFTP 和现有 Agent 安全执行链路的前提下，完成三项能力：

1. 成果物和故障档案可以从客户端内安全删除。
2. 故障档案取消面向用户的数据库备份/恢复入口，改为导出到本地。
3. AI 助手可以读取常见图片、办公文档和指定网页，并给出清晰的兼容性与失败反馈。

## 非目标

- 不删除或修改服务器、SFTP、备份中心中的任何远程文件。
- 不移除故障档案内部 SQLite 持久化、迁移备份和损坏恢复机制。
- 不让网页读取携带用户浏览器 Cookie、登录态或本机代理凭据。
- 不把图片 Base64、完整大文件或网页原文长期写入聊天历史。
- 不在本轮实现通用互联网搜索；“读取指定网址”和“搜索互联网”保持为两项能力。

## 成果物删除

成果物后端已具备受限目录删除能力，本轮补齐工作区入口：

- 成果物列表提供删除菜单。
- 成果物预览头部提供明确的删除按钮。
- 删除前展示成果物名称和影响范围。
- 删除后刷新列表，优先选中下一项；无剩余成果物时展示空状态。
- 删除失败保留当前选中项，并显示可复制的错误信息。

删除只影响成果物仓库中的本地记录和生成文件，不触发 SSH/SFTP 操作。

## 故障档案删除与导出

### 删除

- 故障档案详情页提供删除按钮。
- 二次确认说明删除的是本地档案、备注、状态事件和时间线。
- SQLite 外键负责级联清理备注、状态事件、时间线和全文索引。
- 自动发现候选记录保留，但解除对已删除档案的关联。
- 关联成果物、操作备份、SSH 日志和服务器文件均不删除。

### 导出

- 支持导出当前档案。
- 支持导出当前筛选结果。
- 首批格式为 Markdown、HTML 和 JSON。
- 导出内容包含基本信息、时间线、备注、根因、处理方案、验证状态和关联引用。
- 导出前执行统一脱敏和文本长度限制。
- 导出通过系统保存对话框选择本地路径。

### 存储界面

移除故障档案工作区中的“存储与恢复”入口和手动恢复弹窗。内部 SQLite、自动迁移备份和损坏恢复继续保留并对用户透明。

## AI 内容读取

### 内容摄取边界

所有文件解析、网页下载和图片读取在 Electron 主进程完成。渲染进程只传递文件路径、SFTP 引用或 URL，不直接读取任意本地路径。

统一返回结构：

```js
{
  kind: 'text' | 'document' | 'image' | 'web',
  name: 'example.pdf',
  mimeType: 'application/pdf',
  text: 'bounded extracted text',
  image: {
    mediaType: 'image/png',
    dataUrl: 'data:image/png;base64,...'
  },
  metadata: {},
  truncated: false,
  warnings: []
}
```

### 支持格式

- 文本：TXT、LOG、MD、JSON、YAML、CSV、XML、HTML。
- 文档：PDF、DOCX、XLSX、PPTX。
- 图片：PNG、JPEG、WEBP、GIF 首帧。
- 压缩日志继续沿用现有 GZ、ZIP、TAR.GZ 受限读取。

### 图片分析

- 支持视觉的 OpenAI 兼容模型使用多模态消息内容。
- 模型配置记录视觉能力，可手动设置，也可在一次失败后给出明确兼容性提示。
- 不支持视觉时使用本地 OCR 降级为文本；OCR 不可用时提示切换视觉模型。
- 单次最多 4 张图片，每张限制体积和像素，超过限制时压缩或拒绝。

### 文档解析

- PDF、DOCX、XLSX、PPTX 只提取文字、表格摘要和页/工作表/幻灯片边界。
- 不执行宏、脚本、嵌入对象或外部链接。
- 单个文件和单轮总文本都有字节上限，超限时保留头部、尾部与结构摘要。
- 单个附件失败不会中断同一轮的其他附件和对话。

### 指定网页读取

- 支持用户粘贴 HTTP/HTTPS URL 或点击“引用网页”。
- 主进程执行 DNS 解析并阻止回环、私网、链路本地和云元数据地址。
- 每次重定向重新执行地址校验。
- 不发送浏览器 Cookie、Authorization、Referer 或客户端自定义认证头。
- 限制重定向次数、响应体积、内容类型和请求超时。
- 去除脚本、样式、导航与不可见内容，提取标题、正文和最终 URL。
- Agent 中的网页读取属于只读操作，无需二次确认。

动态登录网站、验证码网站和仅客户端渲染的网站不保证可读取，后续通过浏览器连接器或 MCP 扩展。

## 聊天与上下文

- 当前轮请求按需读取附件，不在聊天数据库保存图片 Base64。
- 历史记录只保存附件名称、类型、来源、提取摘要和截断状态。
- 模型请求统一计算文本、附件和图片预算。
- 每个附件显示独立状态：读取中、可用、已截断、不支持或失败。
- AI 头部显示当前模型能力：文本、文档、图片、网页。

## 安全与审计

- 本地文件必须来自用户选择、粘贴或已连接 SFTP 项目。
- URL 读取记录目标域名、最终 URL、大小、耗时和失败原因，不记录查询参数中的敏感值。
- 文档和网页内容均作为不可信数据包裹，不能改变 Agent 系统指令。
- 所有错误使用稳定错误码，界面不展示本地绝对路径和完整堆栈。
- 删除和导出写入工具审计日志，但不写入文件内容和 API Key。

## 验收标准

- 成果物与故障档案均有可发现的删除入口，删除边界清晰。
- 故障档案工作区不再暴露数据库备份和恢复控件。
- 当前档案与筛选结果可导出为 Markdown、HTML、JSON。
- 常见文本、PDF、DOCX、XLSX、PPTX、图片和公开网页可以作为 AI 上下文。
- 私网 URL、超限文件、不支持格式和不支持视觉模型均有清晰反馈。
- 新增测试通过，原有完整单元测试、构建和关键 E2E 不回归。
