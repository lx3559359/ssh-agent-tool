# ShellPilot 多级服务器分组工作流设计

## 背景

ShellPilot 底层已经具备 `bookmarkGroups`、嵌套分组、分组拖拽和书签移动能力，但新版首页、快速连接和最近连接没有统一接入这些能力：

- 快速连接保存书签时只写入 `bookmarks`，没有登记所属分组。
- 最近连接可以转换为书签，但入口隐蔽，分组选择与服务器管理流程脱节。
- 服务器侧已有分组树能力，但新版界面缺少清晰的新建、移动和批量归组入口。

因此，本次不新建连接数据库，也不重写书签树，而是补齐新版入口并统一所有分组关系写入逻辑。

## 目标

1. 支持可展开、折叠和移动的多级服务器分组。
2. 允许快速连接和历史连接保存到任意分组。
3. 支持服务器拖拽、右键和批量移动到分组。
4. 保证每个服务器只属于一个实际分组。
5. 安全处理旧数据、异常分组关系和非空分组删除。
6. 保持现有 SSH、SFTP、AI、备份和在线更新功能不受影响。

## 非目标

- 不创建独立的“连接管理中心”数据库。
- 不改变书签、历史记录或凭据的既有存储格式。
- 不把“最近连接”“收藏”“全部服务器”保存为实际分组。
- 不在本轮重写现有树组件或连接表单。

## 方案选择

采用“复用现有分组底座并补齐所有入口”的方案。

现有 `bookmarkGroups` 是唯一分组数据源。新版服务器页、快速连接、历史记录和批量管理通过统一的分组关系服务读写它，不再由各组件直接拼接 `bookmarkIds`。

## 界面与交互

### 服务器页

- 服务器列表显示多级分组树。
- 顶部提供醒目的“新建分组”入口。
- 分组支持展开、折叠和层级计数。
- 分组右键菜单包含：
  - 新建子分组
  - 重命名
  - 移动分组
  - 删除分组
- 服务器右键菜单包含：
  - 连接
  - 编辑
  - 复制
  - 移动到分组
  - 删除
- 服务器可以直接拖入任意层级分组。
- 分组可以调整父级和顺序，但不能移动到自身或自己的子级。
- 管理模式支持多选服务器并批量移动到目标分组。

### 快速连接

- “保存为服务器”启用后显示“保存到分组”。
- 分组选择器展示完整多级结构。
- 选择器旁提供“新建分组”，创建完成后自动选中新分组。
- 未手动选择时使用上次保存目标；首次使用默认进入“未分组”。
- 连接记录与分组关系作为同一次保存操作完成。

### 历史连接

- 最近连接提供清晰的右键菜单和悬停操作，不再只依赖小图标。
- “保存到服务器”弹窗展示连接名称、主机、端口、用户和目标分组。
- 分组选择器支持就地新建分组。
- 保存成功后显示“已保存”状态。
- 缺少密码、密钥或凭据配置时仍允许保存，但标记为“认证信息待补充”。

### 虚拟视图

以下入口仅作为筛选，不写入实际分组关系：

- 全部服务器
- 未分组
- 收藏
- 最近连接

其中“未分组”对应系统默认分组，不能删除或重命名。

## 数据模型与统一接口

### 既有数据

- `bookmarks` 保存服务器连接。
- `bookmarkGroups` 保存多级分组以及 `bookmarkIds`、`bookmarkGroupIds`。

不增加新的持久化表。

### 分组关系服务

新增一个无界面依赖的分组关系模块，集中提供：

- `assignBookmarkToGroup(bookmarkId, groupId)`
- `moveBookmarksToGroup(bookmarkIds, groupId)`
- `removeBookmarkFromGroups(bookmarkId)`
- `createBookmarkInGroup(bookmark, groupId)`
- `repairBookmarkMembership(bookmarks, bookmarkGroups)`
- `deleteGroupSafely(groupId, targetParentId)`
- `rememberLastBookmarkGroup(groupId)`

该模块负责：

- 验证服务器和目标分组存在。
- 从其他分组移除服务器，保证唯一归属。
- 对重复 ID 去重。
- 把失效目标回退到默认分组。
- 让调用方获得明确的成功结果或错误代码。

组件不得直接实现自己的 `bookmarkIds` 拼接逻辑。

## 保存与移动流程

### 快速连接保存

1. 校验连接参数和目标分组。
2. 创建服务器书签对象。
3. 写入 `bookmarks`。
4. 通过统一服务登记分组关系。
5. 记住本次目标分组。
6. 如果分组登记失败，撤销刚创建的书签并提示具体原因。
7. 保存成功后再启动连接。

### 历史连接保存

1. 从历史记录构造服务器书签。
2. 展示可编辑名称和目标分组。
3. 检测是否已存在相同连接。
4. 用户可选择打开现有服务器或另存为新服务器。
5. 写入书签和分组关系。
6. 更新历史记录的“已保存”状态。

### 移动服务器

1. 记录原分组关系。
2. 验证目标分组。
3. 从全部实际分组移除服务器。
4. 将服务器加入目标分组。
5. 持久化并记录工具日志。
6. 失败时恢复原分组关系。

## 删除保护

- “未分组”不能删除或重命名。
- 空分组可以直接确认删除。
- 非空分组删除前展示服务器数量和子分组数量。
- 默认行为是把服务器和子分组移动到上一级后删除当前分组。
- 顶级分组被删除时，内容移动到“未分组”。
- 不提供“删除分组并同时删除服务器”作为默认操作。
- 分组不能移动到自身或自己的后代分组。

## 旧数据修复

启动或首次打开服务器页时执行幂等修复：

1. 不属于任何分组的服务器加入“未分组”。
2. 同时属于多个分组的服务器保留第一个有效归属，其余引用移除。
3. 指向不存在服务器的 `bookmarkIds` 被移除。
4. 指向不存在子分组的 `bookmarkGroupIds` 被移除。
5. 分组循环引用沿用现有循环保护规则修复。
6. 每次修复记录数量，不记录密码、密钥等敏感信息。

修复不得删除服务器记录。

## 错误处理

界面错误反馈使用中文并区分：

- 连接已存在
- 服务器记录不存在
- 目标分组不存在
- 分组层级无效
- 数据写入失败
- 操作已恢复

拖拽到无效位置时保持原状态。批量移动失败时整批恢复，不留下部分移动结果。

## 日志与审计

分组操作写入工具日志：

- 创建、重命名、移动和删除分组
- 保存历史连接或快速连接
- 单个或批量移动服务器
- 自动修复异常分组关系

日志记录操作链路编号、服务器 ID、源分组和目标分组，不记录密码、私钥、API Key。

## 测试与验收

### 单元测试

- 服务器唯一归属。
- 批量移动的全量成功和全量回滚。
- 失效目标回退到“未分组”。
- 旧数据重复归组、无归属和失效引用修复。
- 非空分组安全删除。
- 分组循环移动保护。

### 组件与流程测试

- 快速连接保存到指定多级分组。
- 快速连接记住上次目标分组。
- 历史连接保存到指定分组。
- 历史记录已保存状态。
- 就地新建分组后自动选中。
- 右键移动、拖拽移动和批量移动。
- 分组删除时的影响数量和迁移目标。

### 回归测试

- 书签备份导出、导入后层级和归属不变。
- SSH 新建、连接、重连和多标签不受影响。
- SFTP、AI 助手、运维工具、安全中心和在线更新入口不受影响。
- 日间/夜间主题。
- 1366×768 和 1920×1080。
- Windows 100%、125% 和 150% 缩放。

## 完成标准

- 用户无需进入高级设置即可创建多级分组。
- 快速连接和历史连接均可保存到任意分组。
- 服务器可通过拖拽、右键和批量操作换组。
- 任一服务器始终只有一个实际分组归属。
- 删除分组不会意外删除服务器。
- 旧数据可以自动修复且不丢失连接。
- 自动测试和关键界面回归通过后，才允许进入发布流程。
