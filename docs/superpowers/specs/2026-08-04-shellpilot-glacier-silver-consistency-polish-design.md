# ShellPilot Glacier Silver 卡片一致性与可读性修复设计

日期：2026-08-04
状态：用户已确认
基线：ShellPilot `v0.4.32`，提交 `faf17bf`
设计方向：视觉方案 B「清晰立体」
范围：Electron 客户端 UI 表现层，不修改功能、布局结构或业务行为

## 1. 背景与证据

用户在 `v0.4.32` 实机中提供了七张 1920×1080 截图，指出以下一致性问题：

1. 服务器状态页的筛选工具条、空状态按钮和 AI 顶部配置区仍像普通长方形控件，卡片层级不统一。
2. 成果物中心的筛选区及顶部刷新按钮缺少与主面板一致的材质和阴影。
3. 故障档案筛选区偏平，输入提示和部分次要文字过浅。
4. 书签侧栏工具区与搜索区缺少清晰的分组卡片边界。
5. 未连接首页的帮助卡与同级入口卡视觉强度不一致。
6. 运维工具中的快速命令被表现成扁平矩形，缺少操作卡应有的渐变、圆角和阴影。
7. 诊断脚本列表及详情面板偏平，选中态、按钮和标签文字对比度不足。

视觉方案通过本地视觉陪伴页比较 A「克制修补」、B「清晰立体」和 C「强立体银卡」三档强度。用户选择 B，并确认以下原则：

- 内部输入框、下拉框、按钮和标签保持紧凑，只使用轻量控件深度。
- 可点击命令与诊断项属于操作卡，不属于扁平数据行。
- 终端、SFTP 文件行、表格、日志、执行记录和输出继续扁平。

## 2. 根因

本轮问题不是七个独立漏改，而是三类共享规则造成的系统性偏差：

### 2.1 深度令牌过弱

Glacier Silver 在 `v0.4.32` 中把先前较强的阴影和圆角大幅收敛。当前卡片阴影在 1920×1080 的浅色实机背景上与页面底色过于接近，面板和卡片边缘因此难以辨认。

### 2.2 操作卡被误归类为扁平数据

快速命令 `.qm-item` 和诊断脚本 `.operations-tool-list > button` 使用 `--sp-flat-background`、小圆角和 `box-shadow: none`。它们虽然位于高密度界面，但本质是可点击操作入口，应使用操作卡语义。真正需要扁平化的是终端、表格行、日志、历史记录和输出行。

### 2.3 Ant Design 主题映射不完整

当前 `ConfigProvider` 主要映射基础背景、主色和正文色，仍保留 `borderRadius: 3`，并未显式映射容器、次要文字、占位符、禁用文字和组件圆角。页面级 Stylus 覆盖因此与 Ant Design 默认状态相互覆盖，产生矩形控件、低对比占位符及不可读按钮或标签文字。

## 3. 目标与非目标

### 3.1 目标

- 让全客户端外层卡片、工具条、面板和弹层使用一致的 B 档冷银材质、圆角和阴影。
- 让快速命令、诊断脚本、首页入口等可点击操作项统一使用操作卡语义。
- 让正文、次要文字、占位符、按钮和标签在浅色、深色及禁用状态下清晰可读。
- 保持现有功能入口、组件顺序、页面布局、键盘行为、焦点顺序和数据流不变。
- 保持终端、SFTP、表格、日志、历史、任务输出、代码与差异视图紧凑扁平。

### 3.2 非目标

- 不重排或重做客户端信息架构。
- 不改变 SSH、SFTP、AI、运维、安全、成果物或故障档案业务逻辑。
- 不把每个输入框、按钮或标签都做成大阴影卡片。
- 不把表格行、日志行和输出行卡片化。
- 不引入高反光金属条、硬分段渐变、镜面高光或过度发光。
- 不修改主工作区现有的成果物代码、AI 测试或其他用户自有未提交文件。

## 4. 表面分类

### 4.1 控件表面

适用：输入框、下拉框、日期选择、普通按钮、分页、分段控件和标签。

- 圆角：`12px`；极小标签继续使用胶囊形或 `8px` 小圆角。
- 使用两段轻冷银渐变和控件级阴影。
- 聚焦态使用清晰品牌紫焦点环，不改变控件尺寸。
- 禁用态通过底色、边框和图标表达，不通过把文字淡到不可见来表达。

### 4.2 工具条与筛选卡

适用：服务器状态筛选、成果物筛选、故障档案筛选、AI 模型配置组、书签工具组和搜索组。

- 圆角：`16px`。
- 使用比控件更明显、比操作卡更克制的银色渐变。
- 使用卡片级阴影，内部控件使用控件级阴影。
- 保持原有尺寸、换行和排列规则。

### 4.3 操作卡

适用：首页入口、帮助卡、快速命令、诊断脚本、设置分组、摘要卡和可点击工具卡。

- 圆角：`18px`。
- 使用标准冷银复合渐变、顶部柔和内高光和卡片级双层阴影。
- 悬停时只上移最多 `1px` 或提高阴影，不产生大幅位移。
- 选中态保留卡片深度，增加品牌紫描边和低对比品牌底色；不再清空阴影。

### 4.4 分组面板

适用：成果物左右面板、故障档案面板、运维详情、AI 面板、设置分组和侧栏浮层。

- 圆角：`22px`。
- 使用更弱的面板渐变与面板级阴影。
- 内部操作卡保留自身卡片级阴影；只有明确标记为扁平数据的内层取消阴影。

### 4.5 弹层

适用：Modal、Drawer、Popover、Dropdown 和大型覆盖层。

- 圆角：`24px`。
- 使用弹层级渐变、最强阴影和清晰外边界。
- 不改变遮罩、关闭顺序、Escape 行为或焦点恢复。

### 4.6 扁平数据层

适用：终端字符画布、SFTP 文件行、表格行、日志行、历史行、任务输出、代码和差异视图。

- 圆角：按现有密度保持 `0–8px`。
- `background-image: none`，`box-shadow: none`。
- 仅使用细分隔线、悬停底色、选中底色和必要焦点轮廓。

## 5. 浅色 B 档材质

页面底色继续使用 Glacier Silver 的 `#EDF5FB` 点阵背景。标准操作卡采用柔和、连续的复合渐变：

```css
background:
  radial-gradient(
    110% 90% at 15% 0%,
    #FFFFFF 0%,
    rgba(255, 255, 255, 0.72) 34%,
    transparent 72%
  ),
  linear-gradient(
    150deg,
    #F8FBFD 0%,
    #E7EEF4 54%,
    #D8E4EC 100%
  );
```

该渐变保持左上柔白、主体冷银、右下淡冰蓝灰。面板使用更低对比的同源渐变，控件使用两段轻渐变。所有层级禁止使用硬反光带和明显色阶断点。

建议阴影层级：

```css
--sp-shadow-control:
  0 2px 4px rgba(44, 62, 84, 0.10),
  0 7px 15px rgba(54, 77, 103, 0.14);

--sp-shadow-card:
  0 3px 6px rgba(44, 62, 84, 0.13),
  0 14px 27px rgba(54, 77, 103, 0.20);

--sp-shadow-panel:
  0 4px 8px rgba(44, 62, 84, 0.15),
  0 20px 40px rgba(54, 77, 103, 0.23);

--sp-shadow-overlay:
  0 6px 12px rgba(38, 54, 74, 0.18),
  0 28px 52px rgba(49, 70, 96, 0.28);
```

阴影与 `inset 0 1px 0 rgba(255, 255, 255, 0.88)` 顶部内高光组合。阴影不应用于扁平数据层。

## 6. 配套深色材质

Graphite Silver 沿用浅色 B 档的几何和层级关系：

- 卡片从 `#2B3745` 过渡到 `#202A37` 和 `#17212C`。
- 顶部使用低透明白色漫反射高光，不做浅色主题反转。
- 控件、卡片、面板和弹层依次增加深黑阴影强度。
- 卡片和弹层可使用低透明品牌紫外环增强边界。
- 正文、次要文字、占位符和禁用文字按深色表面重新计算对比度。
- 终端主题和终端字符颜色不随本轮界面材质调整。

## 7. 文字、控件与状态

### 7.1 对比度

- 正文、标题、小字号标签和可交互文字最低对比度目标为 `4.5:1`。
- 占位符和次要说明按普通文字可读性处理，不使用接近透明的默认灰色。
- 禁用控件文字最低目标为 `3:1`，禁用状态主要由底色、边框、图标和光标共同表达。
- 主按钮文字固定使用高对比白色；浅色、深色、悬停、聚焦和禁用状态均不得变成低对比灰紫色。
- 语义标签继续使用成功、信息、警告和错误颜色，并同时保留文字或图标说明。

### 7.2 Ant Design 主题映射

`ConfigProvider` 应从共享主题令牌显式映射：

- `colorBgBase`
- `colorBgContainer`
- `colorBgElevated`
- `colorText`
- `colorTextSecondary`
- `colorTextPlaceholder`
- `colorTextDisabled`
- `colorBorder`
- `colorBorderSecondary`
- `borderRadius`
- `borderRadiusSM`
- `borderRadiusLG`

必要时为 Button、Input、Select、Tag、Segmented、Tabs 和 Pagination 增加组件级令牌。不得改变控件高度、交互逻辑、选项内容或事件绑定。

### 7.3 字体协调

- 保留现有字体预设和用户字体选择。
- 页面标题、卡片标题、正文、说明和标签只统一字重与行高层级，不引入新的字体族。
- 标题使用稳定的 `600–700` 字重；说明文字使用常规字重，避免在浅色背景上因过细而发虚。
- 长中文、英文和服务器地址继续使用现有截断与换行策略。

- `.artifact-list-filters` 使用工具条卡材质，内部输入和下拉使用控件材质。

- 成果列表继续作为紧凑列表，不逐行增加大阴影。

### 8.3 故障档案

- `.incident-list-toolbar` 作为工具条卡处理。
- 搜索、服务器、状态、严重级别、服务标签、自定义标签和日期筛选统一可读性与圆角。
- 收藏开关标签使用正文可读颜色。

### 8.4 书签侧栏

- 侧栏外层继续使用面板材质和面板阴影。
- 图标工具组与搜索组建立明确的工具条卡边界。
- 单个图标按钮使用控件级圆角和轻阴影，不扩大点击目标或改变顺序。
- 书签树、历史行和服务器条目继续扁平。

### 8.5 未连接首页

- 新建连接、最近连接、模型 API 和帮助卡全部使用同一操作卡契约。
- 主操作卡继续使用蓝紫品牌渐变。
- 帮助卡不得因文本换行或嵌套规则丢失渐变和阴影。

### 8.6 快速命令

- `.qm-item` 从扁平数据语义改为操作卡语义。
- 使用标准冷银渐变、`18px` 圆角、卡片级阴影和清晰悬停/聚焦态。
- 标题、描述、用途和标签提高可读性；胶囊标签保持紧凑。
- 网格列数、卡片高度、滚动和命令行为保持不变。

### 8.7 诊断脚本与详情

- `.operations-tool-list > button` 从扁平行改为操作卡。
- 选中态保留阴影，通过品牌描边和柔和品牌底色表达。
- `.operations-tool-detail` 使用面板级渐变和更清晰的面板阴影。
- 连接状态、重新识别、说明区和运行按钮按工具条、控件和主按钮语义处理。
- 虚拟日志、任务输出和历史记录继续扁平。

## 9. 全客户端同步检查

除七张截图外，本轮必须同步检查以下共享表面，避免同类遗漏：

- 设置中心全部一级和二级页面。
- AI 面板的配置、聊天、Agent、加载、错误、禁用和附件状态。
- Modal、Drawer、Popover、Dropdown、Tooltip、通知和确认框。
- 帮助、更新、备份同步、连接信息、模型 API、安全中心和 SSH 隧道。
- 首页、服务器、历史、密钥、日志和其他共享工具条。

定向样式只用于无法通过共享令牌和语义类正确表达的边界。禁止新增一个高优先级全局覆盖文件堆叠选择器。

## 10. 实现边界

- 优先修改 `ui-theme-tokens.js`、主题调色板、Ant Design 主题映射和共享 `secondary-ui.styl`。
- 页面样式只修改语义分类错误或缺少表面边界的选择器。
- JSX 仅在现有 DOM 缺少可复用语义类时添加类名；不得调整组件顺序、标签、可访问名称、事件和数据绑定。
- 只允许 UI 表现层改动；不修改 store、API、SSH/SFTP/AI 数据流或安全事务。
- 不触碰主工作区已有的用户修改。

## 11. 异常与回退

- 主题字段缺失或无效时，令牌生成器回退到可读冷白或深石墨实色。
- 浏览器无法渲染复合渐变时，保留 `background-color`、边框和阴影，不能出现透明面板。
- 文本对比度计算失败时，回退到已验证的深色或浅色文本。
- 自定义主题继续从基础色派生语义令牌，不能因缺少 Glacier 专属字段而失去可读性。
- `prefers-reduced-motion: reduce` 下关闭非必要位移和过渡。

## 12. 测试与验收

### 12.1 测试驱动顺序

1. 先增加失败的主题令牌、Ant Design 映射和样式契约测试。
2. 验证失败原因分别对应圆角/阴影不足、操作卡误用扁平语义和文字映射缺失。
3. 进行最小实现使测试通过。
4. 运行相关单元、样式契约和 Electron E2E。
5. 完成浅色/深色实机复拍与设计 QA。

### 12.2 自动化覆盖

- 令牌测试验证浅色与深色的渐变、圆角、四级阴影和文字对比度。
- 样式契约验证工具条、操作卡、面板和弹层使用正确语义。
- 反向契约验证终端、SFTP 行、表格、日志、历史和输出无卡片阴影。
- Ant Design 映射测试验证正文、次要文字、占位符、禁用文字及圆角令牌。
- Electron E2E 覆盖七张截图页面、设置、弹层和 AI 关键状态。

### 12.3 视觉矩阵

- 主题：Glacier Silver、Graphite Silver，并抽查其他内置主题。
- 语言：简体中文、英文。
- 尺寸：`590×400`、`920×600`、`1100×700`、`1600×900`、`1920×1080`。
- 缩放：`75%`、`100%`、`125%`、`150%`、`200%`。
- 状态：默认、悬停、聚焦、选中、禁用、加载、空、成功、警告、错误。

### 12.4 完成条件

- 七张截图中的红框区域都使用正确表面层级。
- 操作卡可见冷银渐变、`18px` 圆角和 B 档阴影，不再呈现为扁平长方形。
- 普通按钮、标签、占位符和禁用态文字清晰可读。
- 深色模式与浅色模式具有同构层级。
- 终端、SFTP、表格、日志、历史和输出保持紧凑扁平。
- 不新增横向溢出、裁切、焦点丢失或布局位移。
- 单元测试、适用 Electron E2E、lint、生产构建和 `git diff --check` 全部通过。
- `apps/electerm-agent/design-qa.md` 记录同视口对照、迭代历史和 `final result: passed`。
