# ShellPilot 授权式内网与登录网页读取设计

日期：2026-08-03
状态：已批准，待实施规划
目标版本：v0.4.28 及后续版本

## 1. 背景

ShellPilot v0.4.27 的“读取网页”功能只允许公网 HTTP/HTTPS 页面。主进程会在网络请求前解析目标域名，只要解析结果包含本机、私网或其他非公网地址，就直接拒绝请求。这一默认策略可以阻止 SSRF，但也让用户无法读取本机网络实际可达的企业内网、设备管理站点和本地服务。

现有读取器使用 Node.js HTTP 客户端获取静态 HTML。即使放开地址限制，它也无法可靠读取需要 JavaScript 渲染、Hash Router、登录 Cookie 或用户交互的 SPA。截图中的 `#/sharingPath` 页面属于这一类，简单 GET 只能取得应用外壳。

本设计在保留默认安全边界的前提下，引入用户授权的内网访问和隔离浏览器读取能力。

## 2. 目标

1. 默认继续允许无需授权的公网静态页面读取。
2. 用户可以对内网或本机站点选择“仅本次允许”或“始终允许此站点”。
3. 支持 JavaScript 渲染、SPA 路由和需要登录状态的页面。
4. 登录状态保存在 ShellPilot 专用隔离会话中，不读取 Chrome、Edge 或系统浏览器的全局 Cookie。
5. 所有跳转和资源请求继续受网络地址策略约束。
6. 永久阻止云元数据、链路本地、组播、未指定地址及非 HTTP/HTTPS 协议。
7. 只向 AI 上下文发送用户确认读取的可见正文，不发送 Cookie、请求头、LocalStorage 或密码字段。
8. 允许用户查看、撤销站点授权并清除隔离网页会话数据。

## 3. 非目标

- 不接管或导入 Chrome、Edge、Firefox 的 Cookie 和浏览历史。
- 不实现通用浏览器、文件下载器或自动填写密码工具。
- 不允许 AI 自主批准新的内网站点。
- 不允许授权绕过永久禁止地址。
- 不采集页面截图、网络请求体、LocalStorage、SessionStorage 或浏览器扩展数据。
- 不保证绕过验证码、企业单点登录策略或网站反自动化机制。

## 4. 方案选择

采用“静态快速路径 + 隔离浏览器升级路径”。

### 4.1 静态快速路径

保留现有 `readPublicWebPage`：

- 仅处理无需授权的公网 HTTP/HTTPS 页面。
- 保留 DNS 解析后固定地址、响应大小、重定向次数和超时限制。
- 对正文充分的 HTML、纯文本和 JSON 继续提供低资源、快速读取。

### 4.2 隔离浏览器升级路径

新增 ShellPilot 专用 Electron 会话与网页阅读窗口：

- 使用固定持久化分区 `persist:shellpilot-ai-web`。
- 启用 `sandbox` 与 `contextIsolation`，禁用 Node 集成。
- 支持 JavaScript、Cookie、Hash Router 和用户登录操作。
- 静态结果明显为空、仅有 SPA 外壳、需要登录，或目标为已授权内网/本机站点时使用该路径。
- 登录失效、正文为空或用户需要交互时显示窗口；已有有效会话时允许后台加载并读取。

不采用接管系统浏览器方案，因为它会扩大 Cookie 与浏览数据访问范围，并依赖不稳定的浏览器调试接口。

## 5. 核心组件

### 5.1 `web-access-policy`

负责 URL 解析、DNS 地址分类、授权判定和永久阻止规则。

返回结构化结果，而不是仅抛出通用错误：

```js
{
  decision: 'allow-public' | 'authorization-required' | 'allow-granted' | 'blocked',
  target: {
    url,
    origin,
    hostname,
    port,
    addresses,
    addressClass: 'public' | 'private' | 'loopback' | 'dangerous'
  },
  reason
}
```

地址类别：

- 公网：保持现有无提示访问。
- 私网：RFC1918、IPv6 ULA 等，需要用户授权。
- 本机：`localhost`、`127.0.0.0/8`、`::1`，需要更强提示后授权。
- 永久禁止：`169.254.169.254` 及链路本地地址、IPv4/IPv6 未指定地址、组播、保留用途地址，以及非 HTTP/HTTPS 协议。

域名存在多个解析结果时采用最严格类别。任何永久禁止地址都会阻止访问；私网与公网混合解析按私网处理并要求授权。

### 5.2 `web-access-grants`

管理站点授权：

- 授权键为规范化的 `协议 + 主机名 + 有效端口`。
- “仅本次允许”保存在主进程内存中，授权一次读取会话，应用重启后失效。
- “始终允许”保存站点键、创建时间和最近使用时间，不保存 Cookie、账号、页面内容或解析 IP。
- DNS 地址每次重新分类，永久授权不能覆盖永久禁止类别。
- 用户可以在设置中撤销单个站点或清空全部授权。

### 5.3 `authenticated-web-reader`

负责隔离浏览器窗口、会话和正文提取：

- 复用 `persist:shellpilot-ai-web` 的 Cookie。
- 主窗口打开时提供受控工具栏：目标站点、加载状态、“读取当前页面”和“取消”。
- 用户可以在窗口中完成登录和必要导航。
- 点击“读取当前页面”后读取当前页面标题、最终 URL 与 `document.body.innerText`。
- 自动读取只在页面加载完成、正文达到最低质量且未检测到明显登录页时执行。
- 正文最长 80,000 字符，超出时明确标记截断。
- 每次读取完成后关闭阅读窗口；持久化会话保留，直到用户在设置中清除。

### 5.4 `web-navigation-guard`

为隔离会话提供统一的导航与资源保护：

- 主框架导航、服务器重定向、客户端跳转和新窗口目标都重新调用访问策略。
- 跳转到新的未授权私网或本机 Origin 时暂停并请求新授权。
- 永久禁止目标立即终止加载。
- 私网子资源只有在其 Origin 已授权时才允许；否则取消请求。
- `window.open` 默认拒绝，受控的同窗口导航继续经过策略。
- 下载、文件协议、自定义协议和外部应用唤起默认拒绝。
- 摄像头、麦克风、定位、通知、MIDI、USB、串口、蓝牙、剪贴板读取和屏幕捕获权限默认拒绝。

### 5.5 设置界面

在设置中增加“AI 网页访问授权”：

- 展示永久授权站点、地址类型、创建时间和最近使用时间。
- 支持撤销单个授权与清空全部授权。
- 提供“清除网页登录数据”，清理 `persist:shellpilot-ai-web` 的 Cookie、缓存、IndexedDB 和站点存储。
- 清除授权与清除登录数据是两个独立操作，均需要确认。

## 6. 用户流程

### 6.1 公网静态页面

1. 用户选择“读取网页”并输入 URL。
2. 策略判定为公网。
3. 静态读取器获取正文。
4. 正文满足质量要求时加入 AI 附件队列。
5. 如正文为空、过短或明显是 SPA 外壳，则升级到隔离浏览器。

### 6.2 首次访问内网或本机站点

1. 主进程解析目标并返回 `authorization-required`。
2. 客户端弹窗显示站点、地址类型、当前 AI 配置及数据发送提醒。
3. 用户选择“仅本次允许”“始终允许此站点”或“取消”。
4. 获得授权后进入隔离浏览器读取。
5. 需要登录时显示窗口；用户登录并点击“读取当前页面”。
6. 提取结果加入 AI 附件队列。

### 6.3 已授权且登录有效

1. 主进程确认永久授权仍有效，重新执行 DNS 分类。
2. 隔离浏览器后台加载页面。
3. 加载完成且正文质量通过时直接返回。
4. 若检测到登录页、空正文、超时或需要用户交互，则显示阅读窗口。

### 6.4 跨站跳转

- 跳转到公网 Origin：继续加载。
- 跳转到相同已授权 Origin：继续加载。
- 跳转到新的私网或本机 Origin：暂停并请求该 Origin 的授权。
- 跳转到永久禁止地址：终止并显示明确原因。

## 7. 授权交互

授权弹窗必须显示：

- 完整规范化 Origin。
- 当前解析出的地址类型，不展示无必要的内部网络详情。
- “网页可见内容将发送给当前 AI 配置 `<配置名称>`”提示。
- 本机服务使用比普通私网更强的风险说明。

按钮：

- `仅本次允许`
- `始终允许此站点`
- `取消`

用户取消属于正常取消，不进入全局错误通知，也不留下失败聊天记录。

## 8. 正文质量与 SPA 判定

静态结果满足任一条件时升级浏览器路径：

- 提取正文少于最低字符阈值，并且 HTML 包含应用挂载节点或大量脚本。
- HTML 标题存在但正文只有加载提示、空壳导航或“请启用 JavaScript”。
- URL 包含 Hash Router 路由，静态正文未包含对应内容。
- 响应或正文表现为登录入口。

隔离浏览器提取：

```js
{
  kind: 'web',
  source: 'browser',
  url: location.href,
  title: document.title,
  text: document.body?.innerText || '',
  truncated
}
```

提取脚本不读取表单字段的 `value`，不访问 Cookie 或 Web Storage。DOM 中已经以普通可见文本展示的内容会被读取，这是用户点击“读取当前页面”的预期行为。

## 9. IPC 与数据边界

Renderer 不直接控制任意 `webContents`，只调用受限 IPC：

- `inspectAIWebTarget(url)`：返回安全分类或错误。
- `authorizeAIWebTarget(origin, scope)`：只接受当前待授权请求生成的一次性令牌。
- `readAIWebPage(url)`：启动受策略保护的读取流程。
- `completeAIWebRead(readId)`：用户确认提取当前页面。
- `cancelAIWebRead(readId)`：取消并销毁窗口。
- `listAIWebGrants()`、`revokeAIWebGrant(origin)`、`clearAIWebGrants()`。
- `clearAIWebSessionData()`。

主进程为每次待授权请求生成短期令牌，绑定规范化 Origin、解析类别和发起窗口。Renderer 不能通过伪造参数直接写入授权。

## 10. 错误处理

提供可操作的结构化错误：

- `WEB_ACCESS_AUTH_REQUIRED`：需要用户授权。
- `WEB_ACCESS_CANCELLED`：用户取消，不显示系统错误。
- `WEB_ACCESS_BLOCKED`：永久禁止目标。
- `WEB_LOGIN_REQUIRED`：需要在隔离窗口登录。
- `WEB_READ_EMPTY`：页面加载完成但没有可提取正文。
- `WEB_READ_TIMEOUT`：页面或动态内容加载超时。
- `WEB_CERTIFICATE_ERROR`：证书验证失败，不自动忽略。
- `WEB_NETWORK_ERROR`：DNS、代理或连接失败。
- `WEB_REDIRECT_LIMIT`：重定向次数超过限制。

错误信息不得包含 Cookie、Authorization Header、URL 内凭据或页面敏感正文。

## 11. 安全约束

1. 用户授权是网络访问授权，不是证书忽略、浏览器权限或下载授权。
2. AI 和网页内容不能自行创建授权；只有用户界面确认可以完成授权。
3. 每次 DNS 解析都重新应用永久禁止规则。
4. 静态公网路径继续使用固定 DNS 地址，保持对 DNS Rebinding 的现有防护。
5. 浏览器路径对每个主框架目标和资源 URL 执行访问策略；未授权私网资源被取消。
6. 隔离分区不与主应用页面或系统浏览器共享 Cookie。
7. 隔离网页不获得 ShellPilot preload、IPC、Node API 或文件系统能力。
8. 诊断日志只记录规范化 Origin、地址类别、决策和错误码，不记录查询参数、Hash、Cookie 或正文。

## 12. 测试策略

### 12.1 单元测试

- IPv4/IPv6 公网、私网、本机和永久禁止地址分类。
- 多地址 DNS 采用最严格类别。
- URL 凭据、非 HTTP(S) 协议和异常端口拒绝。
- 授权按协议、主机和有效端口隔离。
- 仅本次授权消费与应用重启语义。
- 永久授权写入、列出、撤销和清空。
- 永久授权不能覆盖危险地址。
- 结构化错误不泄露敏感参数。
- 静态正文质量和 SPA 升级判定。

### 12.2 主进程组件测试

使用可注入的 Electron 适配器验证：

- 隔离 Session 分区和 BrowserWindow 安全参数。
- 权限请求、下载、新窗口与协议拦截。
- 导航和重定向重新授权。
- 正文提取只返回标题、最终 URL 和可见文本。
- Cookie、LocalStorage、密码字段和请求头不会进入返回值或日志。
- 窗口关闭、取消和超时都释放 `webContents` 与监听器。

### 12.3 E2E 测试

本地启动受控 HTTP 服务，覆盖：

- localhost 首次授权、仅本次授权和永久授权。
- 登录表单设置 Cookie 后访问受保护页面。
- SPA 在 JavaScript 执行后更新正文和 Hash Router。
- 已登录会话的后台复用。
- 登录失效后重新显示窗口。
- 跳转到第二个本机 Origin 时重新授权。
- 永久禁止地址和未授权私网子资源被拦截。
- 设置界面撤销授权和清除登录数据。

### 12.4 回归验证

- 现有 `ai-content-ingestion.spec.js` 全部通过。
- 公网静态页面读取行为和限制保持不变。
- 文件、图片、Office 文档与 SFTP 附件摄取不受影响。
- AI 对话不会持久化浏览器会话数据或授权令牌。
- 中英文文案和窄窗口布局通过现有 UI 测试。

## 13. 迁移与发布

- 当前版本没有内网站点授权数据，不需要迁移。
- 新功能默认关闭所有私网与本机访问，必须由用户逐站点授权。
- 更新后原有公网读取行为保持兼容。
- 发布说明明确区分“站点授权”和“登录数据”，并说明网页正文会发送给当前 AI 配置。
- 首个版本不提供通配符域名、CIDR 段授权或全局“允许全部内网”开关，避免授权范围失控。

## 14. 验收标准

1. 截图中的 SPA 链接可以在隔离窗口完成登录/加载，并将当前可见正文加入 AI 上下文。
2. 首次访问私网或本机 Origin 时出现明确授权弹窗。
3. “仅本次”不会在应用重启后保留；“始终允许”可以在设置中撤销。
4. 已授权站点登录状态可以复用，清除网页登录数据后失效。
5. 新私网 Origin、危险地址、下载、弹窗和浏览器权限不会继承原授权。
6. Cookie、LocalStorage、密码字段和请求头不会出现在 AI 请求、聊天历史或日志中。
7. 公网静态读取性能和现有功能不回退。
8. 新增测试、现有相关单元测试、lint 和生产构建全部通过。
