# ShellPilot 中文使用手册

ShellPilot 是一款面向 Windows 的 SSH 与智能运维客户端。它以成熟 SSH 终端和 SFTP 能力为基础，集成服务器状态、运维工具、AI 对话与 Agent、安全备份、快捷回滚、故障档案、成果物和在线更新。

本手册面向第一次接触 SSH 的用户。每一节都说明入口、操作步骤、结果判断、常见问题和安全注意事项。

## 1. 第一次使用：5 分钟快速上手

### 1.1 添加第一台服务器

1. 打开 ShellPilot。客户端默认显示首页，不会自动打开本地终端或连接服务器。
2. 点击顶部“新建”，填写名称、服务器 IP 或域名、SSH 端口和账号。
3. 选择密码或私钥认证并填写对应信息。
4. 点击“测试连接”。测试成功后再保存。
5. 从左侧“服务器”双击刚保存的服务器。
6. 首次连接时核对主机指纹；确认指纹来源可信后再接受。

### 1.2 验证 SSH 和 SFTP

连接成功后，在终端依次执行这些只读命令：

```bash
whoami
hostname
uptime
df -h
```

看到正常输出说明基础 SSH 可用。随后切换到“SFTP”，确认能打开远程目录、返回上级和刷新目录。

### 1.3 配置 AI

1. 点击顶部“模型 API”。
2. 选择服务商模板，或直接填写兼容 OpenAI 的 API 地址。
3. 填写 API Key，点击“拉取模型”。
4. 选择模型并测试连接。
5. 测试成功后保存。
6. 在右侧 AI 助手顶部选择配置名称和模型。

### 1.4 第一次使用的安全原则

- 首次连接陌生服务器时必须核对主机指纹。
- 不要在公共电脑保存生产服务器密码。
- 不要把密码、私钥、API Key、Cookie 或客户数据粘贴到聊天中。
- 先执行只读检查，再执行修改。
- 修改网络、防火墙、SSH 和关键配置前，先准备云控制台、VNC 或其他带外登录方式。

## 3. 新建连接、快速连接与多级分组

### 3.1 新建正式连接

首页点击“新建连接”，按向导填写：

1. **基本信息**：名称、主机/IP、端口。
2. **账号与认证**：账号、密码、私钥或 SSH Agent。
3. **测试并连接**：先测试，再保存和连接。

SSH 默认端口通常是 `22`，但应以服务器实际配置为准。新手不需要填写 SSH Agent、MFA、登录脚本、代理跳板等高级选项。

### 3.2 快速连接

“快速”适合临时服务器。填写 IP、端口、账号和认证信息即可连接。

快速连接成功后，如果以后还要使用：

1. 打开连接菜单。
2. 选择“保存为服务器”。
3. 选择目标分组。
4. 补充名称并保存。

### 3.3 历史连接

左侧“历史”会记录最近连接。历史记录可以重新连接，也可以保存到服务器书签和指定分组。清理历史记录不会删除正式服务器书签。

### 3.4 多级分组

服务器支持多级分组，例如：

```text
生产环境
  ├─ 华东
  │   ├─ Web
  │   └─ Database
  └─ 华南
测试环境
```

常用操作：

- 在服务器侧栏创建父分组或子分组。
- 把新建连接、快速连接或历史连接直接保存到指定分组。
- 通过右键菜单移动或复制服务器。
- 重命名分组只修改本机显示名称。
- 删除非空分组前，先移动或处理其中的服务器和子分组。

移动和分组操作只影响本机书签，不会修改远程服务器。

### 3.5 编辑、复制和删除

在服务器上点击右键可以编辑、复制、查看连接信息或删除。删除书签不会删除远程服务器，但会移除本机保存的连接资料。

## 4. 认证、密钥与主机指纹

### 4.1 密码认证

填写账号和密码。生产环境建议逐步改用密钥认证，并限制 `root` 直接登录。

### 4.2 私钥认证

1. 在连接配置中选择私钥认证。
2. 选择本机私钥文件。
3. 私钥已加密时填写私钥密码。
4. 测试连接后保存。

私钥文件不要上传到网盘、代码仓库或 AI 服务。

### 4.3 SSH Agent

只有本机已经正确配置 SSH Agent 时才启用。新手默认关闭即可。Agent 路径、环境或密钥未加载时，开启该选项反而会导致认证失败。

### 4.4 主机指纹

首次连接会显示主机指纹。指纹变化可能来自服务器重装、SSH 主机密钥轮换，也可能是中间人攻击。无法确认原因时不要直接接受新指纹。

### 4.5 跳板机

使用跳板机时，目标服务器和跳板服务器的地址、账号、认证信息和主机指纹都要分别正确。证书、私钥和代理路径只保存在本机安全位置。

## 5. SSH 终端

### 5.1 常规操作

- 按 `Enter` 直接执行命令。
- `Ctrl+C` 中断当前命令。
- `Ctrl+Shift+C` / `Ctrl+Shift+V` 复制和粘贴，实际行为可在设置中调整。
- 使用多标签同时连接多台服务器。
- 使用分屏对比输出。
- 使用搜索查找当前终端输出。
- 使用右键菜单复制、粘贴、搜索和查看相关操作。

手工终端输入按原生 SSH 行为直接发送，不做二次确认或自动恢复点。AI、快捷命令、运维工具和其他受控入口发起的操作会根据风险进入对应安全流程。

### 5.2 长时间任务

长任务建议使用：

```bash
tmux
screen
nohup command > output.log 2>&1 &
```

这样即使本地网络中断，任务也不容易随 SSH 会话结束。

### 5.3 多标签与分屏

- 每个标签对应独立会话。
- 关闭标签会结束该会话，但不删除服务器书签。
- 分屏适合同时观察日志、资源和部署命令。
- 终端异常时先保存重要输出，再重新连接。

### 5.4 手工终端与受控安全流程的边界

手工终端输入按原生 SSH 行为直接发送，客户端不会在回车前拦截、分类或自动建立恢复点。执行手工修改命令前，请自行核对目标、备份和带外恢复方式。

AI、快捷命令、运维工具和其他受控入口会在发送命令前进入安全流程，并尝试区分：

1. 只读命令：直接执行。
2. 可恢复修改：先建立恢复点并验证，再确认执行。
3. 未知或不可自动恢复修改：明确提示风险后确认。
4. 禁止操作：直接阻止。

即使通过受控入口，`vim`、`nano`、交互式 shell、动态脚本和第三方程序内部写入也无法保证提前识别全部副作用。此类操作应先手工备份。

## 6. 状态总览与服务器状态中心

### 6.1 状态总览

左侧“状态总览”用于多服务器运维。它会集中展示：

- 已保存服务器及其连接状态。
- 最近一次状态采集时间。
- CPU、内存、磁盘等资源告警。
- 异常服务、容器和平台组件。
- 最近失败的运维或安全任务。

批量状态适合发现“哪台服务器需要先处理”，单机状态适合进一步查看具体信息。

### 6.2 当前服务器状态

先连接 SSH，再点击顶部“服务器状态”：

1. 点击“刷新检测”。
2. 查看系统、资源、服务、网络、防火墙、安全和容器。
3. 切换“平台与服务”，查看自动识别的 Nginx、Docker、数据库、面板或其他平台组件。
4. 点击服务异常项查看状态、端口、进程和日志摘要。
5. 需要 AI 帮助时点击“AI 诊断”。

状态中心使用只读命令，不使用 `sudo`，不会修改配置，也不会后台定时扫描。

### 6.3 平台与服务自动识别

客户端会根据 systemd 服务、进程、安装路径和 Compose 项目归组平台与服务。无法识别时可以添加自定义规则：

- 服务名前缀。
- 精确服务名。
- 安装路径前缀。
- Compose 项目名。

“权限受限”表示当前账号没有读取权限，不等于正常；“不支持”表示系统缺少相应命令或组件。

### 6.4 异常一键诊断

1. 在异常服务或告警旁点击“AI 诊断”。
2. AI 先生成只读排查计划。
3. 检查每一步命令、用途和停止条件。
4. 确认后执行。
5. 实时查看进度，可随时取消。
6. 结果可复制、导出或发送给 AI 继续分析。

任何修改、未知或禁止命令都会被只读计划拦截。

## 7. SFTP 文件管理与传输任务

### 7.1 浏览文件

连接服务器后切换到“SFTP”。左侧为本地目录，右侧为远程目录。

支持：

- 进入目录、返回上级和刷新。
- 上传、下载、覆盖、复制、移动和重命名。
- 新建目录、修改权限和删除。
- 文本文件预览和编辑。
- 远程文件一键备份。
- 把远程文件拖到 AI 对话框。

### 7.2 上传和下载

上传前检查目标路径、目录权限、磁盘空间和同名覆盖。下载前检查本机保存位置和空间。

当前 SFTP 标签页有上传或下载任务时，文件管理器底部会自动显示紧凑进度栏。点击“展开详情”可查看当前标签页内每个任务的方向、文件名、进度、速度和控制按钮；右键打开的全局传输中心仍可用于查看其他标签页的任务。快速完成的任务会短暂保留完成状态，便于确认结果。

SFTP 传输任务会显示：

- 文件名和传输方向。
- 已传输大小和总大小。
- 进度条、速度和预计剩余时间。
- 运行、暂停、继续、完成或失败状态。

### 7.3 暂停、继续与重试

在任务列表中暂停或继续传输。继续前客户端会校验服务器、路径和文件指纹。远端文件已变化时不会盲目续传，应重新确认目标。

失败后先检查：

1. SSH/SFTP 是否仍在线。
2. 目录和文件权限。
3. 服务器与本机磁盘空间。
4. 同名文件和覆盖策略。
5. 网络是否稳定。

### 7.4 同名文件和传输安全

上传、覆盖、同端复制或移动会尽量在目标端建立受限快照并校验结果。取消后如果目标已部分写入，可到安全中心检查恢复记录。

下载只修改本机目标，不属于远程回滚。FTP 与 SFTP 不同，FTP 操作不支持自动回滚。

### 7.5 一键备份

选中远程文件或文件夹后点击“一键备份”。备份默认保存在远程 `.shellpilot-backups` 目录。大目录备份前先检查空间；数据库目录和持续写入目录应使用对应数据库或应用自己的备份方案。

### 7.6 远程文本编辑与权限

远程编辑器保存失败时会保留当前编辑内容，可修正权限后直接重试。错误提示会标明实际 SFTP 登录身份和失败阶段，不再把内部事务临时路径当作用户文件。

终端里执行 `su` 或 `sudo` 只改变终端进程身份，不会改变已经建立的 SFTP 连接身份。ShellPilot 不会猜测或自动填写 `sudo` 密码，也不会通过终端注入命令绕过 SFTP 权限。需要修改受保护文件时，应使用具备目标目录写入和文件替换权限的账号建立 SFTP 连接，或先在服务器端按运维规范调整权限。

即使 SFTP 登录身份是 `root`，服务器仍可能因只读文件系统、ACL/SELinux、不可变属性、chroot 或 SFTP 服务限制拒绝写入。此时应检查服务器端限制，而不是反复点击保存。

## 8. 运维工具

顶部“运维工具”统一分为：

- **常用操作**：高频只读查询和少量参数化维护。
- **诊断脚本**：组合多条只读命令形成诊断结果。
- **安全维护**：涉及修改，必须经过预览、备份和确认。
- **执行记录**：查看历史结果、失败原因和任务状态。

### 8.1 新手推荐流程

遇到问题时按下面顺序：

1. 服务状态。
2. 监听端口。
3. 最近日志。
4. CPU、内存和磁盘。
5. 网络、DNS 和路由。
6. 再决定是否需要修改。

### 8.2 参数表单

需要参数的工具会显示表单，不要求新手手工拼接命令。例如：

- 服务名称从已发现服务中选择，可多选。
- 网卡从服务器真实网卡中选择。
- 端口、IP、域名和日志关键词使用独立输入框。
- 独立抓包可选择真实网卡、TCP/UDP/ICMP、可选主机和端口、最多包数、最长时长和 `.pcap` 保存路径。
- 抓包属于资源敏感诊断：执行前必须核对范围并确认；目标文件已存在时不会覆盖。
- 修改网络可填写 IP/CIDR、网关、DNS、等待时间和回滚保护。

### 8.3 只读诊断

只读诊断不修改服务器，不需要二次确认。常见范围包括：

- 系统、CPU、内存、Swap、磁盘和进程。
- TCP/UDP、DNS、路由、MTU、出口 IP 和时间同步。
- 防火墙状态、暴露端口和登录安全。
- systemd、Nginx、Docker、日志和证书。
- 目录占用、计划任务、软件包和平台服务。

新增现场排查包括异常进程与 D/Z 状态、文件描述符与 Socket 压力、NFS/CIFS 挂载健康、SMART/软 RAID 健康以及时间同步状态。缺少 `smartctl`、`mdadm`、`chronyc` 等可选工具时只显示降级结果和安装建议，不会自动安装。

抓包生成的 pcap 二进制文件不会自动发送给 AI；“交给 AI 分析”只包含结构化范围、文件元数据和有限报文头摘要。

### 8.4 安全维护

修改类工具会显示最终命令、影响范围、备份和回滚方式。确认前不会执行。执行后到安全中心查看验证结果和“立即回滚”入口。

## 9. 模型 API 配置

### 9.1 最简配置

首屏只需要：

1. API 地址。
2. API Key。
3. 模型。
4. 保存并测试。

API 地址可以是基础地址、带 `/v1` 的地址或完整接口地址。程序会尽量识别兼容路径。

### 9.2 拉取多个模型

点击“拉取模型”获取当前 API 支持的模型。保存后，AI 助手顶部左侧选择配置名称，右侧选择该配置下的任意模型。

### 9.3 多组 API

可分别保存官方服务、中转站和本地模型。不同提供商的地址、Key、模型、代理和高级参数相互独立。

### 9.4 状态判断

- **可用**：最近一次检测成功。
- **检测中**：正在请求模型接口。
- **失败**：显示失败原因、延迟和最近检测时间。
- **未配置**：尚未保存有效的地址和 Key。

状态是最近检测结果，不保证服务商一直在线。失败时检查地址、Key、余额、模型权限、代理和接口兼容性。

### 9.5 高级设置

API 路径、认证 Header、角色、语言、代理、Skill 和 MCP 位于高级选项。不了解时保持默认。

## 10. AI 对话与 Agent

### 10.1 对话模式

用于解释命令、分析错误、总结日志、生成排查建议。`Enter` 发送，`Shift+Enter` 换行。

同一会话会保留上下文。长对话采用分页和虚拟滚动，不会一次渲染全部历史。离开底部后收到新消息会显示未读消息数量，点击“回到最新”返回末尾。

### 10.2 Agent 模式

Agent 会分步骤使用允许的终端、文件和 Skill 能力。它不是固定功能列表，但仍受权限与风险策略限制。

只读操作，例如查看状态、读取文件、列目录和查询日志，不要求二次确认。写入、删除、覆盖、重启、网络、防火墙和权限修改必须确认。

### 10.3 AI 接管

AI 接管按 SSH 会话独立开启，默认关闭。只有连接到主机密钥已验证的 SSH 会话才能启用。

1. 连接目标 SSH。
2. 打开“AI 接管”。
3. 检查当前账号和服务器。
4. 让 AI 先执行只读检查。
5. 修改类任务会展示差异、备份和确认。
6. 点击“一键停止”可中断当前 AI/Agent 任务。

关闭接管、断开 SSH 或退出客户端后，接管不会自动延续。

### 10.4 引用上下文

- **引用终端**：读取当前终端的限长输出。
- **引用选中**：只读取终端中选中的文字。
- **引用文件**：读取当前 SFTP 文件。
- **生成命令**：根据当前问题生成命令建议。
- **上传**：选择本机附件。
- **读取网页**：输入公网、内网或本机 HTTP/HTTPS 地址，将页面中可见的限长正文作为当前请求的上下文。

也可以把 SFTP 文件拖入对话框，或从剪贴板粘贴文件。

支持直接分析 PDF、DOCX、PPTX、XLSX、常见文本文件，以及 PNG、JPEG、WebP 和 GIF 图片。图片只在当前请求中作为视觉内容发送，不写入聊天历史。

#### 网页读取与内网授权

网页读取按目标类型采用不同路径：

1. 公网页面优先使用静态快速读取；如果页面是 JavaScript 应用、登录页或只有加载外壳，则自动进入隔离网页读取器。
2. 内网与本机 localhost 页面必须按来源授权。可以选择“仅本次允许”或“始终允许此来源”；重定向到另一个受保护来源时会再次确认。
3. 需要登录时，账号操作在 ShellPilot 专用的隔离登录会话中完成。它不会导入 Chrome 或 Edge 的登录状态，只会把最终页面的可见限长文本交给当前 AI，不会提取密码、请求头或浏览器存储。
4. 在“设置 → AI 网页访问”中可以撤销永久授权、清空全部授权，或单独清除隔离登录数据。撤销授权不会自动清除登录数据，反之亦然。
5. 带账号凭据的 URL、非 HTTP(S) 地址、链路本地地址、云元数据地址、组播、未指定和其他保留地址始终被拦截，不能通过授权放行。

### 10.5 取消、超时和断线

AI 请求和 Agent 任务支持停止。超时、断线或模块加载失败时会显示明确提示。停止 AI 不等于已撤销远程修改，已发送命令的最终状态应在终端和安全中心核对。

### 10.6 多文件修改

AI 修改多个文件时应先生成统一差异审查：

1. 列出每个目标文件。
2. 显示原内容摘要和修改差异。
3. 创建备份或恢复点。
4. 用户一次确认。
5. 执行后逐项验证。
6. 失败时按记录回滚。

## 11. 成果物中心

成果物是可预览、轻量修改、导出和交付的正式文件，不等同于普通聊天回复。

### 11.1 创建成果

在 AI 对话或 Agent 模式中点击“生成成果”，选择模板：

- 运维诊断报告。
- 服务器巡检报告。
- 服务器资产清单。
- 运维变更记录。
- 安全检查报告。
- 故障复盘报告。
- 自定义文档。
- 自定义表格。

### 11.2 支持格式

- 文档：Markdown、HTML、DOCX 和 PDF。
- 表格：CSV、XLSX 和 PDF。

### 11.3 预览和修改

左侧“成果物”打开成果物中心：

1. 从列表选择成果物。
2. 在右侧预览正文或表格。
3. 修改标题、章节、单元格或说明。
4. 保存后形成新版本，旧版本继续保留。
5. 选择格式并保存到本机、外部打开或上传当前服务器。
6. 不再需要的成果物可以在列表或预览区确认删除。

上传到服务器前必须确认远程路径和文件名。

删除成果物只会删除本机成果物记录及其生成文件，不会删除 SSH 或 SFTP 服务器上的文件。

### 11.4 成果生成失败

先点击“重新加载模块”。仍失败时：

1. 查看工具日志中的错误编号和链路编号。
2. 缩小引用的终端输出或附件。
3. 确认模板字段完整。
4. 重新生成，不要反复提交同一失败工具调用。

## 12. 故障档案

故障档案保存一次故障的生命周期；成果物保存可交付的报告。二者互相关联，但职责不同。

### 12.1 自动产生待确认异常

下列来源发现异常时，会在本机生成“待确认异常”：

- 状态总览和服务器状态。
- 运维任务失败。
- 安全事务或回滚异常。
- AI/Agent 任务失败。

这一步只整理已有事件，不会建立正式档案，不会上传云端，也不会额外执行 SSH 命令。

### 12.2 审核异常候选

1. 打开左侧“故障档案”。
2. 进入“待确认异常”。
3. 查看来源、服务器、证据、严重级别和重复次数。
4. 需要跟踪时点击“确认建档”。
5. 修改标题、摘要、标签和严重级别后保存。
6. 不需要时选择忽略；可在“已忽略”中重新打开。

相同异常会合并计数，避免产生大量重复档案。

### 12.3 手动建档

也可以点击“新建档案”，填写：

- 标题。
- 关联服务器。
- 严重级别。
- 故障现象与影响。
- 服务标签和自定义标签。

### 12.4 排障时间线

关联的诊断、Agent、安全操作、回滚和成果物会追加到事件时间线。处理过程中补充根因、处置、验证和复盘备注。

标记“已解决”前必须记录人工或自动验证结果。

### 12.5 生成故障复盘

从正式档案生成复盘成果物时，会带入：

- 故障影响。
- 事件时间线。
- 诊断证据。
- 根因分析。
- 恢复过程。
- 验证结论。
- 改进计划。

生成后在成果物中心人工检查，再导出 DOCX、PDF、HTML 或 Markdown。

### 12.6 导出与删除

故障档案可以导出为 Markdown、HTML 或 JSON 文件。导出由主进程统一限制大小并过滤常见密码、API Key、Token 和认证头；导出后仍应在共享前人工检查业务敏感信息。

不再需要的档案可以确认删除。删除正式档案会清理其本地时间线和关联关系，但不会删除待确认异常、服务器文件、备份或日志。客户端不再提供手动数据库备份/恢复入口，数据库内部仍保留必要的自动保护能力。

## 13. 安全操作中心、备份与回滚

顶部“安全中心”集中展示终端、AI、运维工具、服务器状态、SFTP 和 SSH 隧道产生的任务与恢复记录。

### 13.1 页面说明

- **执行中**：运行、暂停或取消中的任务。
- **可回滚**：已有验证恢复点的修改。
- **历史记录**：完成、失败、取消和保留修改的记录。
- **旧版记录**：只用于兼容旧数据。

可按服务器、来源、状态或关键词筛选。

### 13.2 修改类操作流程

1. 识别目标服务器和风险。
2. 检查磁盘空间和备份大小。
3. 创建备份或恢复点。
4. 验证恢复资料可用。
5. 展示最终命令或文件差异。
6. 用户确认。
7. 执行并验证。
8. 选择保留修改或立即回滚。

### 13.3 快捷回滚

看到“立即回滚”时，确认记录对应的服务器、账号、目标文件和时间，再点击回滚。重新连接后必须匹配原主机、端口和账号。

回滚完成后还会进行验证。回滚失败时不要重复盲目执行，应使用备份和带外控制台处理。

### 13.4 取消不是回滚

取消任务只请求停止当前执行。命令已经产生的修改不会自动消失。任务停止后检查状态，再决定是否回滚。

## 14. SSH 隧道与端口转发

SSH 隧道也叫 SSH 端口转发，用于把本地端口、远程端口或目标服务通过现有 SSH 连接安全转发。

顶部“SSH 隧道”支持：

- **本地转发**：本机端口访问服务器或服务器内网服务。
- **远程转发**：远程服务器通过指定端口访问本机服务。
- **SOCKS5 动态代理**：应用通过本机 SOCKS5 端口访问目标。

### 14.1 本地访问远程 MySQL 示例

```text
类型：本地转发
本机监听：127.0.0.1:3307
目标地址：127.0.0.1:3306
```

然后数据库工具连接 `127.0.0.1:3307`。

### 14.2 健康状态和断线记录

隧道管理器显示运行、停止、异常和最近断线原因。可测试、编辑、重启或停止。SSH 断开、关闭会话或退出客户端时会清理对应监听端口。

### 14.3 常见错误

- `EADDRINUSE`：监听端口已被占用。
- `administratively prohibited`：SSH 服务端禁止转发。
- 目标拒绝连接：服务器无法访问目标地址或服务未监听。

优先监听 `127.0.0.1` 或 `::1`。不要把数据库和管理后台直接监听到公网。

## 15. 大日志与压缩日志、附件分析

### 15.1 大日志

不要一次把完整大日志发送给 AI：

1. 说明故障时间、服务和现象。
2. 按错误码、请求 ID、关键词或时间范围搜索。
3. 分段读取故障附近内容。
4. 内容不足时继续读取下一段。
5. 只把关键片段发送给 AI。

### 15.2 压缩日志

支持 `.gz`、`.zip` 和 `.tar.gz`。先查看压缩包文件列表，再选择目标日志。超大压缩包应先在服务器上按时间和关键词筛选。

### 15.3 附件限制

终端输出、附件和工具结果进入模型前会限制大小。被截断时缩小时间范围、关键词和文件数量，不要关闭限制后直接发送敏感大文件。

图片原始数据只在当前请求期间保存在内存中；聊天历史仅保存文件名和文字摘要。BMP、SVG 和其他未支持图片格式会在发送前明确拒绝。附件解析失败时不会继续发起空的 AI 请求。

## 16. Skill、MCP 与 CLI

### 16.1 Skill

Skill 是可复用的 Agent 工作流程和知识包。默认不内置任何用户 Skill。

创建方式：

1. 在模型 API 高级设置进入 Skill 管理。
2. 点击“通过对话创建”。
3. 用自然语言描述目标、输入、步骤和输出。
4. AI 生成草稿。
5. 检查文件、权限、命令和风险。
6. 通过验证后手动启用。

声明权限不等于获得授权。Skill 中的修改命令仍要走安全策略。

### 16.2 MCP

MCP 可接入 CMDB、Prometheus、知识库和工单等外部工具。只登记可信服务，并限制网络、权限和数据范围。

### 16.3 CLI

CLI 可引用本机允许列表中的命令行工具，例如已经登录的 Codex CLI。账号登录和权限由对应 CLI 自己管理。

当前聊天栏未启用的 MCP/CLI 入口不会显示，避免占用空间。后续启用后仍需检查命令与参数。

## 17. 备份同步与换电脑迁移

顶部“备份同步”用于导出或导入客户端配置。

建议流程：

1. 导出服务器连接、分组和设置。
2. 包含密码或私钥资料时使用强密码加密。
3. 把备份放在可信存储。
4. 新电脑安装同版本或更高版本 ShellPilot。
5. 导入前先备份新电脑现有配置。
6. 导入后抽查地址、端口、账号、分组、私钥路径和 API 配置。

默认导出不应包含 API Key；需要重新填写密钥时按提示操作。不要把未加密备份上传公开网盘、GitHub 或聊天工具。

## 18. 发布版本与在线更新

### 18.1 检查更新

点击顶部“检查更新”查看：

- 当前版本。
- 最新正式版本。
- `[新增]`、`[修复]`、`[改动]` 更新说明。
- 更新源。
- 下载进度和错误原因。

### 18.2 更新源

- **自动选择（推荐）**：优先 ModelScope 国内源，失败后回退 GitHub。
- **ModelScope 国内源**：适合国内网络。
- **GitHub**：适合可稳定访问 GitHub 的网络。

### 18.3 正式发布规则

只有通过本地验证、构建安装包、上传发布资产并写入发布批准清单的版本才会推送。开发构建、单独 Git 标签和未批准安装包不会进入客户端在线更新。

每个正式版本单独保留，不覆盖或删除上一版本资产。升级出现问题时可从历史 Release 获取上一版本安装包。

### 18.4 更新前注意

1. 保存正在编辑的文件。
2. 等待 SFTP 传输完成或暂停。
3. 检查长时间远程任务是否已放入 `tmux`/`screen`。
4. 点击更新并等待下载完成。
5. 按提示重启。

客户端内更新仍会运行安装程序，但应使用静默升级参数，不再要求重新选择安装范围和路径。

## 19. 设置、主题、缩放与窗口

### 19.1 主题

顶部“日间/夜间”快速切换明暗模式。设置页可调整界面主题和终端主题。终端核心区域保持深色背景，避免界面主题影响命令辨识度。

### 19.2 语言

设置页选择语言后先预览，点击“应用”才保存。取消或关闭设置会恢复原语言。

### 19.3 Windows 缩放

支持常见的 100%、125% 和 150% 缩放。1366×768 或窄窗口下，侧栏和面板会自动收紧或滚动。AI 面板空间不足时可临时收起。

### 19.4 窗口操作

双击顶部栏可最大化或还原。还原会恢复最近可用窗口尺寸，并保持不小于可用的最小工作区。

## 20. 工具日志与崩溃恢复

### 20.1 工具日志

左侧“日志”记录启动、SSH、SFTP、AI、Agent、界面和更新问题。日志包含操作链路编号，便于关联前端、SSH、Agent 和更新流程。

反馈问题时提供：

- ShellPilot 版本。
- 问题发生时间。
- 完整操作步骤。
- 错误编号和链路编号。
- 截图。
- 对应时间附近的工具日志。
- 是否稳定复现。

### 20.2 错误页

正式错误页只显示错误编号和可复制诊断信息，不应直接展示完整本机路径、密钥或长堆栈。详细信息保存在本机日志。

### 20.3 崩溃恢复

发生异常退出后重新打开客户端，会进入崩溃恢复流程：

- 恢复可安全重开的标签页。
- 提示未完成任务。
- 不会自动重放未知远程命令。
- 可打开安全中心检查任务最终状态。

如果每次启动都出现数据库迁移 `Done` 弹窗或自动重启，应查看工具日志并报告版本与链路编号。

## 21. 常见问题

### 21.1 SSH 连接失败

检查 IP、端口、网络、防火墙、账号、密码/私钥、主机指纹和服务器 `sshd` 状态。

### 21.2 SSH 可用但 SFTP 不可用

检查服务器 SFTP 子系统、目录权限、磁盘空间和当前会话状态。

### 21.3 AI 显示“未配置”

打开“模型 API”，填写并保存 API 地址与 Key，拉取模型并测试连接。示例模板不等于已配置。

### 21.4 AI 显示“检测中”很久

检查网络、API 地址、代理和服务商状态。可手动停止检测后重试。不要连续快速重复提交。

### 21.5 AI 没有上下文

确认仍在同一聊天会话；不要清空会话或切换到新任务。需要终端或文件内容时主动使用引用按钮。

### 21.6 运维工具参数显示 `[object Object]`

这是表单值解析异常。不要执行生成的命令，记录工具名称、字段和版本，并查看工具日志。

### 21.7 任务完成但安全中心仍显示执行中

刷新安全中心并检查 SSH 是否断开。仍未收口时不要重复启动同一修改任务，先取消或等待状态同步。

### 21.8 SFTP 传输失败

检查连接、权限、空间、同名文件和网络。使用任务记录重试，覆盖类操作先确认恢复点。

远程编辑器提示权限不足时，先核对错误中的 SFTP 身份。终端内的 `su`/`sudo` 不会改变该身份；`root` 仍被拒绝时检查只读挂载、ACL/SELinux、不可变属性和 SFTP/chroot 限制。编辑内容会保留，可处理权限后重试。

### 21.9 大日志读不全

使用关键词搜索、时间范围、分段读取和继续读取。压缩包先查看文件列表。

### 21.10 成果物生成失败

点击“重新加载模块”，减少上下文和附件后重试。仍失败时记录错误编号与链路编号。

### 21.11 更新检查失败或速度慢

选择“自动选择”或切换 ModelScope/GitHub 后重试，并保存更新日志。

### 21.12 修改网络后服务器失联

立即使用云控制台、VNC 或 KVM 登录，执行安全中心生成的回滚脚本或恢复原配置。不要反复修改防火墙和路由。

## 22. 上线前安全检查清单

执行生产修改前逐项确认：

- [ ] 已确认当前服务器、端口和账号。
- [ ] 已保留云控制台、VNC、KVM 或其他带外入口。
- [ ] 已创建业务备份、文件备份或云快照。
- [ ] 已检查磁盘空间和备份大小。
- [ ] 已阅读最终命令、文件差异和影响范围。
- [ ] 已确认回滚入口和恢复资料通过验证。
- [ ] 未把密码、私钥、API Key 或客户数据发给未知 AI/MCP/CLI。
- [ ] 长时间任务已放入 `tmux`、`screen` 或可靠后台服务。
- [ ] 执行后已完成服务、端口、日志和业务验证。
- [ ] 故障或变更已记录到故障档案或成果物。
