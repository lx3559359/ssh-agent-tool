# ShellPilot v0.4.13

## [新增]

- 新建 SSH 连接改为三步向导：主机与端口、账号与认证、测试并连接；高级选项默认折叠，降低首次连接门槛。
- 未连接首页新增最近服务器、新建连接、配置模型 API 和帮助入口，避免空白页面影响使用。
- 模型 API 推荐区支持搜索、国内/国际/本地筛选，并标注 OpenAI 兼容接口；保存后可直接测试连接。
- 运维工具新增“新手推荐”流程：服务状态、端口监听、日志和网络检查；未连接时可直接跳转建立 SSH 连接。

## [修复]

- 修复窗口从最大化还原时可能缩小到不可用尺寸的问题；优先恢复上次可用窗口大小，并设置合理下限。
- 窄窗口下仅自动收起 AI 面板，保留终端和信息面板的可用空间。
- 修复模型 API 仅套用模板时仍被误显示为已配置的问题；未保存或未检测的配置会明确引导完成配置。
- 修复运维工具、AI 配置和首页在 1366x768、1920x1080 及 Windows 缩放下的布局回归。

## [改动]

- 统一运维入口命名为“运维工具”，内部使用“常用操作 / 诊断脚本 / 安全维护 / 执行记录”。
- AI、状态中心、帮助和更新相关界面继续按需加载，减少首次启动时的前端负担，同时保留 SSH 终端核心稳定性。
- 补充连接向导、首页、模型推荐、响应式布局和运维未连接引导的自动化回归测试。
