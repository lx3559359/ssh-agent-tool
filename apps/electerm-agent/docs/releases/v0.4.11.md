# ShellPilot v0.4.11

## [新增]

- 新增断开连接首页，启动客户端后不再自动打开本地终端，可直接新建 SSH 连接、打开书签或使用快速连接。
- 新增 AI 与 Agent 任务停止能力，流式对话、工具调用和执行计划均可随时取消。
- 新增对话式 Skill 创建流程，支持从自然语言生成、校验、预览并保存 Skill 草稿。
- 新增运维工具箱，提供快捷操作、24 项只读诊断、安全维护和 10 套多步骤只读巡检脚本。
- 新增系统资源、网络、安全、UDP、服务、容器和国产 Linux 兼容性诊断，支持实时进度、取消、历史记录和交给 AI 分析。
- 新增安全维护工作区，修改类操作统一执行预检、备份、确认、结果校验和回滚记录。

## [修复]

- 修复生成的 Skill 校验失败后无法继续编辑和保存的问题。
- 修复 AI 或 Agent 触发后无法及时停止、取消状态未正确同步的问题。
- 修复只读查询、读取文件和切换路径等无风险操作仍被强制二次确认的问题。
- 修复运维任务完成后仍显示执行中、阻止后续任务启动的问题。
- 修复脚本中心切换工具时残留上一任务面板，以及部分脚本在缺少 Podman 事件时等待过久的问题。
- 修复运维工具箱中文文案、样式加载、窄窗口布局和任务历史同步问题。

## [改动]

- 将快捷命令入口升级为运维工具箱，按快捷操作、诊断脚本、脚本中心和安全维护区分不同使用场景。
- 默认主页保持未连接状态，减少启动开销，并保持常规 SSH 终端核心逻辑不变。
- 只读巡检脚本限定为无修改命令；涉及系统、网络、服务和文件变更的操作继续进入安全维护与回滚流程。
- 更新 Windows 安装包、便携包、GitHub Release 和 ModelScope 国内更新源至 0.4.11。
