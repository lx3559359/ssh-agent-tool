# ShellPilot v0.4.39

## [新增]

- 快捷命令、运维脚本和抓包任务改为通过当前 SSH 标签页的受控 PTY 执行，能够识别 `su`、`sudo -i`、`sudo -s` 等方式切换后的当前 Shell 有效身份。
- 运维任务与历史记录分别显示 SSH 登录用户和当前 Shell 用户，便于确认命令实际以哪个身份执行。

## [修复]

- 修复先以普通用户登录、再切换到 `root` 后，快捷命令和脚本仍按原登录用户判断权限，导致抓包等命令无法使用的问题。
- 修复进入子 Shell 后原 Shell Integration 失效，运维任务无法可靠跟踪命令边界的问题；现在会在确认空闲提示符后为当前子 Shell 重建跟踪。
- 修复任务取消后提示符恢复状态无法确认时仍可能释放终端的问题；现在会标记“取消结果未知”并要求重连恢复。

## [改动]

- 环境探测和任务步骤在同一个独占终端租约内完成，并校验标签页、终端进程、登录用户、主机、端口和主机密钥指纹，防止会话切换后误执行。
- 当前 Shell 已是 `root` 时抓包命令直接执行 `tcpdump`；非 root 时仅尝试无交互的 `sudo -n`，不会卡在密码提示。
- SFTP 上传、下载和远程文件操作继续使用 SSH 登录身份，不受终端内 `su` 身份切换影响。
