# ShellPilot v0.4.44

## [新增]

- SSH 隧道现已提供本地转发、远程转发和 SOCKS5 动态代理的分层状态检测，可分别识别 SSH 连接、端口监听、目标可达性与端到端流量状态。
- 运行中的隧道会直接显示可访问地址、浏览器打开方式、复制命令和代理配置；SOCKS5 会给出独立浏览器配置示例，帮助新手正确使用代理。
- 新增完整的 SSH 隧道入门指南与故障诊断，可按隧道类型查看配置示例、访问步骤、安全提示和服务器端转发策略检查方法。

## [修复]

- 修复重连、停止或控制器切换后旧状态可能被误认为当前隧道正常的问题，并加强异常目标、IPv6 地址和远程转发诊断。
- 修复 ExcelJS 流式读取工作簿时可能因压缩流提前结束而失败的问题，安装依赖时会自动应用兼容补丁。

## [改动]

- 隧道运行卡片会根据实际检测证据展示“已连接”“监听正常”“可访问”或具体异常，不再用单一测试结果掩盖访问边界。
- 帮助中心与内置使用说明补充浏览器何时需要代理、远程转发从哪里访问，以及常见 SSH 服务端配置项的通俗说明。
