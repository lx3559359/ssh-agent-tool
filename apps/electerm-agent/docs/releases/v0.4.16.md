# ShellPilot v0.4.16

## [新增]

- 增加原生 SSH 隧道管理器，支持本地转发、远程转发和 SOCKS5 动态代理。
- 增加 HTTP、HTTPS、MySQL、PostgreSQL、Redis 常用隧道模板，可自动带入推荐端口。
- 支持按服务器保存多条隧道配置，并可设置 SSH 连接成功后自动启动。
- 增加隧道启动、停止、重启、连接测试和运行状态查看，失败隧道不会影响其他隧道和当前 SSH 会话。

## [修复]

- 修复旧版单条隧道配置与新版多隧道管理器之间的兼容问题。
- 修复 SSH 断开后隧道监听未及时释放，以及重连时可能遗留旧运行状态的问题。
- 修复隧道管理器关闭时误影响终端会话的风险。
- 修复公开监听地址缺少明确风险确认，以及瞬时提示导致自动化操作不稳定的问题。
- 修复全新开发环境缺少 Electron 端到端测试依赖、导致测试脚本只能在旧依赖目录中运行的问题。

## [改动]

- 隧道数据转发改为客户端原生 SSH 通道，不向终端输入命令，也不依赖服务器安装额外工具。
- 将 SSH 隧道入口加入顶部工具栏，并补充中文帮助说明。
- 隧道管理界面改为按当前服务器隔离配置，终端关闭时统一清理该会话创建的运行实例。
