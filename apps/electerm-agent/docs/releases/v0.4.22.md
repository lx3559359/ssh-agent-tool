# ShellPilot v0.4.22

## [新增]

- AI 对话与 Agent 现在可以统一读取本机上传、拖放、剪贴板和 SFTP 中的 PDF、DOCX、PPTX、XLSX、文本及常见图片。
- 新增“读取网页”入口，可将指定公网 HTTP/HTTPS 页面的限长正文加入当前请求，并拦截本机、内网、带凭据地址和重定向绕过。
- 成果物与故障档案新增确认删除；故障档案支持安全导出 Markdown、HTML 和 JSON。
- 图片以一次性多模态内容发送给支持视觉的模型，使故障截图和监控图表可以直接参与普通对话与 Agent 分析。

## [修复]

- 修复 SFTP 中的图片、PDF 和 Office 文档被旧纯文本预览链路当作二进制文件拒绝的问题，同时保留大日志分段读取和压缩日志成员预览。
- 修复 Node.js 22 在网页读取中使用多地址 DNS 回调时的兼容问题，公网网页可正常读取且内网防护继续生效。
- 修复不支持的 BMP、SVG 图片可能在界面显示已发送、实际被模型过滤的问题。
- 修复附件解析失败后仍可能继续发起一次无有效上下文 AI 请求的问题。

## [改动]

- 图片原始数据仅在当前请求期间保存在内存中，聊天历史只保存文件名和文字摘要，避免数据库膨胀。
- 故障档案取消面向用户的手动数据库备份/恢复入口，保留内部自动保护；导出与删除不会影响 SSH/SFTP 服务器文件、备份或日志。
- 成果物删除限制在受校验的本地成果目录，不会递归触碰远程服务器路径。
- 保留 `v0.4.21` 及更早版本的全部发布资产；本次更新仅新增 `v0.4.22`，不会覆盖历史版本。
