# ShellPilot v0.4.33

## [新增]

- 新增全客户端卡片材质一致性验收，覆盖状态总览、成果物、故障档案、服务器侧栏、运维工具、AI 面板以及浅色与深色主题的关键状态。

## [修复]

- 修复服务器状态、成果物、故障档案、服务器侧栏、运维工具与 AI 面板中部分外层区域仍呈直角、纯白或弱阴影，导致卡片层级不一致的问题。
- 修复浅色与深色模式下部分按钮、标签、占位文字、禁用态文字和模型选择器对比度不足，文字难以辨认的问题。

## [改动]

- 外层卡片与面板统一采用平滑的白色至冷银渐变、圆角边界和清晰立体阴影；顶部品牌栏继续保持连续蓝紫色带。
- 配套的“石墨冷银”深色模式同步更新表面层级与文字状态；终端、SFTP、表格、日志、历史记录和任务输出继续保持紧凑扁平。
- 保持当前客户端布局、功能位置、SSH/SFTP/AI 工作流程和用户数据兼容性不变。
