# ShellPilot v0.4.45

## [新增]

- 书签使用普通 SSH 账户登录后，在同一终端通过 `su` 切换到 root 时，ShellPilot 现在会识别当前有效 root 身份，并为远程文件面板启用完整的 root 文件能力。
- root 文件能力覆盖目录浏览、双击编辑、上传、下载、新建、改名、权限调整、安全删除和快速删除；登录账户与当前文件操作身份会分别显示，避免混淆。

## [修复]

- 修复客户端始终按书签登录账户判断 SFTP 权限，导致 `su root` 后仍无法双击编辑或操作 root 文件的问题。
- 修复远程列表补偿刷新后编辑器会话失效、保存一直加载，以及外部编辑器并发关闭时可能残留临时文件或监听器的问题。
- 修复 Windows 本地文件 mode 包含类型位时 root 上传被错误拒绝的问题，并保持远端权限参数的严格校验。
- 修复用户按 `Ctrl+C` 取消 root 文件传输后，传输历史可能被错误记录为失败的问题；普通错误和超时仍会保持失败状态。
- 修复隐藏 SFTP 预加载失败后，用户切换到 SFTP 面板不会重新初始化、界面长期停留在“文件操作：未知”的问题。
- 修复 Vite 8 / Rolldown 生产构建可能生成空或语法损坏 renderer bundle 的问题。

## [改动]

- root 文件操作通过与当前 SSH 终端绑定的受控 PTY 协议执行，大文件内容使用仅登录账户可访问的私有暂存区传输；不会猜测、保存或回放 `su`/`sudo` 密码。
- 加强 root 文件事务的目录、inode、权限、摘要、目标占用和清理证明；取消、失败及关闭流程会等待资源收口并保留可核对的恢复证据。
- 新增真实本地 SSH/SFTP 端到端回归，覆盖 root 身份切换、编辑、传输、改名、权限、删除、取消以及退出 root 后恢复普通账户权限。
