# ShellPilot v0.4.18

## [新增]

- SFTP 上传和下载任务增加实时进度、暂停、继续、取消与重新开始入口；客户端重启后保留安全的任务记录，并明确标记需要重新开始的传输。
- SSH 隧道增加健康状态、探测延迟、端口冲突提示、断线原因与最近事件记录。
- AI 多文件修改增加统一差异审查，可逐个选择要应用的文件，并在写入前集中确认。
- 安全操作中心统一展示 SFTP 传输、SSH 隧道、AI 修改、备份和回滚记录。

## [修复]

- 修复全新配置中缺少统一任务数据表时，安全操作中心加载失败并遮挡主界面的问题。
- 修复 SQLite、NeDB 和旧数据迁移未保存统一任务记录的问题。
- 修复可选任务历史读取失败时连带隐藏原有备份与回滚记录的问题。

## [改动]

- SFTP、隧道和 AI 修改继续复用现有 SSH 会话与安全事务链路，不改变普通 SSH 终端输入、快捷键和连接流程。
- 安全中心内运行中、已暂停、失败和已完成任务使用统一状态与中文说明，便于恢复、重试和审计。
- 本版本经本地门禁和真实服务器回归验证后发布；GitHub 与魔塔更新资产分别保留，旧版本继续独立保留。
