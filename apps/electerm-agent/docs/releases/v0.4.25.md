# ShellPilot v0.4.25

## [新增]

- 新增恢复计划加载失败的匿名质量事件，便于诊断启动恢复问题，同时不记录路径、凭据或原始异常内容。

## [修复]

- 修复恢复提示在取消或执行失败时仍被清除的问题；失败状态现在会保留，便于重试并显示错误。
- 修复 MCP 组件重复初始化后监听器叠加、工具被重复执行，以及缺少请求标识时产生孤立副作用的问题。
- 修复 SFTP `Unexpected packet` 重试分支不可达、重连时会话标识被覆盖，以及卸载后定时器和句柄未完整清理的问题。
- 修复快捷连接在不同入口使用重复解析逻辑而可能产生行为差异的问题，并保留现有协议与输入兼容性。
- 修复 Windows 打包依赖、失效脚本入口和开发启动文档与实际工程不一致的问题。

## [改动]

- 完成三轮使用者视角、代码质量和发布工程复核，共确认并修复 11 项实现或生命周期问题。
- 重新核对此前 166 项功能要求：159 项满足、6 项因授权外部环境而部分满足、1 项已由新交互取代，未发现未满足或未验证项目。
- 完整单元测试、代码规范、质量与恢复 E2E、性能 E2E、Windows 打包、应用启动冒烟和依赖安全审计均通过。
- 保留 `v0.4.24` 及更早版本的全部历史资产；本次只新增 `v0.4.25`，不会覆盖历史版本。
