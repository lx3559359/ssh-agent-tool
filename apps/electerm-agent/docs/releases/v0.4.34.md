# ShellPilot v0.4.34

## [新增]

- 新增运维工具主操作按钮与终端会话标签的高对比度回归测试，覆盖浅色卡片主题、固定深色终端栏及其交互状态。

## [修复]

- 修复运维工具“运行脚本/连接后运行”按钮内部文字被辅助说明样式覆盖，出现紫色背景上文字难以辨认的问题。
- 修复终端会话标签、添加标签按钮及滚动控件沿用浅色界面文字颜色，在固定深色终端栏上对比度不足的问题。

## [改动]

- 终端会话栏改用独立于界面主题的前景色令牌：活动标签使用白色，非活动标签与辅助控件使用高对比浅灰色。
- 保持客户端布局、终端画布、SSH/SFTP/AI 工作流程与用户数据兼容性不变。
