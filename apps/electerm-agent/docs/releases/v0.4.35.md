# ShellPilot v0.4.35

## [新增]

- 新增“网络抓包与报文采样”独立诊断工具，支持 TCP、UDP、ICMP、ICMPv6 和不限协议的结构化过滤条件。
- 新增异常进程、文件描述符压力、挂载与文件系统健康、磁盘与 SMART 健康、系统时间同步五项只读现场排查工具。

## [修复]

- 修复旧版抓包入口在运维工具迁移后被隐藏并错误映射到 UDP 综合检查，导致通用抓包能力消失的问题。
- 修复抓包取消或异常中断时临时文件清理不完整的问题，并保留旧抓包 ID、收藏、历史记录和深链接兼容。

## [改动]

- 抓包调整为资源敏感操作：运行前显示目标主机、网卡、过滤范围、包数、时长和保存路径，并要求一次性确认。
- 抓包最多 1000 个报文、最长 300 秒，目标文件不覆盖，pcap 不自动上传给 AI，也不会自动安装 tcpdump、SMART 等可选依赖。
