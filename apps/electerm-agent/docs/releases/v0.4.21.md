# ShellPilot v0.4.21

## [新增]

- 新增故障档案辅助采集流程，可从异常服务器、失败任务和安全操作中生成候选记录，经用户确认后归入故障档案。
- 新增候选记录筛选、确认、忽略和关联成果物能力，减少重复整理诊断过程的工作量。
- 重写中文使用手册，覆盖首次连接、SSH、SFTP、服务器状态、AI 助手、成果物、故障档案、安全回滚、隧道、日志、Skill、MCP、CLI 和在线更新等完整流程。
- 扩充客户端帮助中心，使常用入口、安全边界和故障恢复说明可直接在客户端内查看。

## [修复]

- 修复 SFTP 请求和终端文件传输在极快响应时可能先返回结果、后注册监听器，导致任务一直等待的问题。
- 修复 SFTP 会话关闭时缺少确认和超时兜底，可能残留通道或影响后续连接的问题。
- 修复安全事务使用新 SFTP 连接而不是当前会话共享连接，可能造成身份上下文不一致的问题。
- 修复文件冲突处理在覆盖、重命名、跳过和目录合并场景下的测试不稳定问题。
- 修复自动化测试在 Electron 启动上下文切换、无默认本地终端和慢速文件传输时产生误报的问题。

## [改动]

- 故障档案继续采用“辅助采集、人工确认”的方式，不会把普通 SSH 输出自动保存为正式档案。
- SFTP 关闭改为优雅结束并设置强制回收上限，兼顾正常退出和异常连接恢复。
- 文件传输和安全回滚验证增加真实服务器覆盖，包括中文路径、大文件、目录冲突和恢复流程。
- 保留 `v0.4.20` 及更早版本的全部发布资产；本次更新仅新增 `v0.4.21`，不会覆盖历史版本。
