# ShellPilot v0.4.12

## [新增]

- Skill 对话创建增加草稿自动规范化，可将自然语言生成结果整理为符合规范的 `SKILL.md` 与 `skill.json`。
- Skill 校验失败时提供中文原因和可操作建议，便于继续修改后保存。

## [修复]

- 修复部分模型生成中文 Skill 标识、无效版本号、缺失触发器或权限字段时提示 `Skill package did not pass validation` 的问题。
- 修复 AI 与 Agent 停止后请求状态未完整清理、后续对话可能仍受上一次任务影响的问题。
- 修复运维工具箱部分窗口尺寸、主题和 Windows 缩放比例下的布局回归。
- 修复真实服务器回归测试与性能基线中发现的任务状态同步问题。

## [改动]

- 运维工具箱打开后保持显示，由用户手动关闭，避免执行和查看结果时面板自动退出。
- 清理旧底座遗留的更新、云同步与品牌入口，统一使用 ShellPilot 自有服务和发布地址。
- 补充 Skill 创建、AI 会话、运维工具、视觉布局、性能与真实服务器自动化测试。
