# ShellPilot v0.4.41

## [新增]

- SFTP 远程文件右键菜单新增“快速删除（不可恢复）”，确认后直接永久删除，不创建恢复快照。
- 快速删除支持文件与文件夹批量处理，最多并行执行 4 项，并在完成后统一刷新远程列表。

## [修复]

- 修复 Windows 本地文件被系统或其他程序锁定时，文件夹上传因 `EBUSY`、`EACCES` 或 `EPERM` 整批失败的问题；现在会跳过锁定项并继续上传可读文件。
- 修复跳过项经过 UI 运行时状态复制后仍可能进入实际上传、再次触发 `EBUSY` 的问题。
- 修复永久删除确认框未显示危险操作红色按钮的问题。

## [改动]

- 上传完成提示会汇总成功、跳过和失败数量，进度坞保留可见的完成状态与逐项结果。
- 原“安全删除（可恢复）”继续保留；需要恢复能力时仍可使用安全删除，需要速度时可选择快速删除。
