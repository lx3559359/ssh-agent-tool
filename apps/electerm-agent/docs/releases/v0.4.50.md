# ShellPilot v0.4.50

> SFTP 有效身份与终端提示符修复版本。

## [新增]

- 新增 `hik → su/su -/sudo -i → root → exit` 的完整 SSH/SFTP 身份切换回归覆盖。

## [修复]

- 修复 SFTP 打开或双击目录时向可见 SSH 终端重复追加提示符的问题；内部身份探测继续严格校验，但不再污染终端缓冲区。
- 修复裸 `su` 密码回车覆盖已认证 Shell 切换状态，以及子 Shell 继承失效 `PROMPT_COMMAND` 后 root 文件身份无法确认的问题。
- 修复 root 与登录用户切换期间复用旧目录快照、过期绘制或不确定清理结果的问题；身份不明、权限拒绝或会话变化时立即清空旧结果并安全拒绝操作。
- 修复密码粘贴、分片密码提示及内部 OSC 生命周期记录可能导致密码状态残留或提示符泄漏的问题。

## [改动]

- SFTP 目录请求按终端会话串行执行，每次操作独立确认当前有效身份；同一身份仍可使用 30 秒内存缓存，跨身份缓存严格隔离。
- 内部 SFTP 受控命令只隐藏自然提示符文本，已认证 Shell 生命周期边界仍完整保留，用于可靠恢复终端输入状态。
