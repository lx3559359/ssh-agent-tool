# ShellPilot v0.4.20

## [新增]

- 新增多级服务器书签分组，可在侧栏创建、重命名、移动和删除分组。
- 新增统一的服务器分组选择器，支持在新建连接、快速连接和历史连接中直接选择目标分组。
- 新增将快速连接与历史连接保存到指定分组的入口，减少重复填写服务器信息。

## [修复]

- 修复删除分组时可能错误处理仍包含服务器或子分组的情况，并在操作前给出明确提示。
- 修复服务器在多分组间移动、复制或取消归组时的成员关系不一致问题。
- 修复紧凑窗口顶部新增 SSH 隧道入口后，界面回归测试仍按旧操作数量判断的问题。
- 修复视觉回归测试依赖真实在线更新检查，网络延迟时可能产生误报的问题。

## [改动]

- 服务器分组写入改为原子操作，失败时不会留下部分更新的数据。
- 分组树、书签右键菜单和移动弹窗统一使用同一套成员关系规则。
- 保留 `v0.4.19` 及更早版本的全部发布资产；本次更新仅新增 `v0.4.20`，不会覆盖历史版本。
