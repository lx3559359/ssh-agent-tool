# ShellPilot v0.4.28

## [新增]

- 新增经用户明确授权后读取本机与内网页面的能力；按来源提供单次授权和长期授权，未授权的私有地址仍不会自动访问。
- 新增隔离网页读取窗口，支持登录表单、HttpOnly Cookie 和 SPA 动态内容，并可在同一隔离会话中复用登录状态。
- 新增 AI 网页访问设置，可查看和撤销长期授权，也可一键清除全部授权或隔离网页的登录数据。

## [修复]

- 修复本机网络能够访问内网页面时，AI 仍统一提示“只能读取公网网页”而无法继续的问题。
- 修复登录表单 POST 导航可能被改写成 GET 的问题，以及跨源重定向被重复取消时可能触发 Electron 崩溃或产生竞态的问题。
- 修复被安全策略主动拦截的导航先显示底层加载错误、覆盖结构化授权提示的问题。

## [改动]

- 公网页面继续使用原有快速读取路径；私有地址仅在授权后进入独立的 `persist:shellpilot-ai-web` 分区，外部协议、弹窗、下载和权限请求保持拒绝。
- 跨源跳转必须针对新来源重新授权；链路本地地址、云元数据地址、组播/保留地址、带 URL 凭据的地址和非 HTTP(S) 协议继续禁止访问。
- 仅把最终 URL、标题、可见文本、来源和截断状态交给 AI，不导出 Cookie、网页存储、认证头或完整 DOM；本地文件与 SFTP 内容读取行为保持不变。
- 合并后自检通过：3195 项单元测试中 3189 项通过、0 失败、6 项按环境跳过；生产构建成功，内网授权与隔离读取 E2E 2/2 通过。
