# ShellPilot v0.4.24

## [新增]

- 全面启用 Aurora Lift 视觉体系，统一连接工作台、终端、SFTP、服务器状态、AI 成果、设置和运维工具等页面。
- 优化五套内置主题在紧凑窗口、高缩放及中英文界面下的颜色、焦点态、禁用态和响应式表现。

## [修复]

- 修复部分页面卡片、面板与弹层的阴影深度不足，以及不同页面圆角层级不一致的问题。
- 修复部分紧凑窗口、高缩放和深色主题状态下的视觉溢出、焦点辨识度与禁用态对比度问题。

## [改动]

- 卡片、面板与弹层采用更明显的双层立体阴影和顶部高光，深色主题增加黑色深度阴影与紫色外环。
- 扩大控件、工具条、卡片和弹层圆角，并保留表格行、日志行、文件行与终端字符画布的平面层级。
- 完成 20 张全页面视觉预览和 17 组同视口前后对照。
- 完成 408 个真实应用页面及弹层状态的尺寸、缩放、语言、主题、焦点、对比度和溢出检查。
- 本次更新仅调整 UI 主题 token 与样式，不改变 SSH、SFTP、终端、AI、路由、数据或快捷键功能。
- 保留 `v0.4.23` 及更早版本的全部发布资产；本次更新仅新增 `v0.4.24`，不会覆盖历史版本。
