# ShellPilot v0.4.30

## [新增]

- Agent 默认启用完整运行预算，限制总耗时、模型请求、工具调用、工具参数与结果大小；达到上限时会安全停止并保留明确的结束原因。
- 新增可见的 Agent 运行阶段、计数、取消结果和诊断任务恢复状态；应用重启或视图关闭后仍可识别已完成、失败、取消和待恢复任务。
- 新增安全只读工具并行调度与上下文压缩指标，在保持写入和状态类工具串行执行的前提下缩短多项查询等待时间。

## [修复]

- 修复 Agent 后端取消未等待确认、取消失败后过早释放会话锁，以及运行期间 SSH 端点变化可能继续执行的问题。
- 修复工具调用参数重复解析、超大参数或模型响应未被统一限制，以及异常工具调用可能影响同批合法调用的问题。
- 修复本地 Agent 观测写入失败被静默忽略的问题；失败现在经脱敏、本地、单次限频的诊断通道报告，不影响主任务。

## [改动]

- 将 Agent 工具目录、执行、风险生命周期、运行服务、预算、调度、取消和任务视图拆分为独立模块，降低耦合并强化行为测试。
- Agent 运行事件仅保存在本地，只记录稳定状态、计数和不透明运行标识，不记录主机、账号、命令、输出、凭据或完整对话。
- 保持现有 AI 配置、聊天记录、SSH/SFTP、安全确认和工具调用协议兼容；新增保护默认生效，无需迁移或手动开关。
