# ShellPilot v0.4.26

## [新增]

- 新增授权真实服务器外部验收，覆盖连接态双栏 SFTP、完整文件操作、远程转发、SOCKS5、目标拒绝错误和远端沙箱清理。

## [修复]

- 修复部分 SFTP 服务不返回设备编号时，跨目录拖拽移动被误判为跨文件系统而拒绝的问题；同端移动现在使用原子 SFTP `rename`。
- 修复 SFTP 文本编辑保存时，变更摘要翻译参数错误导致确认弹窗渲染失败、保存一直处于等待状态的问题。
- 修复隧道启动后目标拒绝或服务器禁止转发时，运行态错误缺少稳定错误码和可执行处理建议的问题。

## [改动]

- 重新核对 166 项既有功能要求：163 项满足、2 项因服务器策略/独立官网环境而部分满足、1 项已由新交互取代；没有未满足或未验证项目。
- 外部验收严格限制在远端 `/tmp/.shellpilot-*` 随机沙箱和回环端口，不修改、重启或重载服务器现有服务、sshd、防火墙或业务目录。
- 保留 `v0.4.25` 及更早版本的全部历史资产；本次只新增 `v0.4.26`，不会覆盖历史版本。
