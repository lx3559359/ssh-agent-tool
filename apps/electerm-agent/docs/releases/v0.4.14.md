# ShellPilot v0.4.14

## [新增]

- AI 助手新增运维办公产物工作区，可生成并预览 Markdown、HTML、CSV、Excel、Word 和 PDF 文件，并支持另存、下载和继续轻量修改。
- AI 接管新增任务模式与工具作用域，可在已验证的 SSH 会话中创建、修改和读取文件；只读操作直接执行，风险修改进入安全确认与回滚流程。
- AI 产物支持绑定终端、选中文本、SFTP 文件和诊断结果作为来源，同时限制上下文与输出大小，避免长日志拖慢对话。
- GitHub 发布流程新增历史版本保护：版本标签或 Release 已存在时立即终止，禁止覆盖旧安装包和更新资产。

## [修复]

- 修复客户端启动时重复显示 `Done / Database Migrated`、重启或闪退后再次打开的问题，数据库迁移改为首个窗口创建前一次性完成。
- 修复运维工具参数被渲染成 `[object Object]`、输入后无法继续编辑，以及只读诊断按钮文字与背景对比度不足的问题。
- 修复 AI 接管对安全只读命令误拦截、跨服务器上下文误用和任务无法正确中止的问题。
- 修复 AI 产物并发保存、路径越界、文件名冲突、敏感信息脱敏及 Office 文件生成异常。
- 修复低高度窗口、1366×768、Windows 125%/150% 缩放下 AI 面板和连接向导的挤压、遮挡与禁用文字不清晰问题。

## [改动]

- 新建连接继续采用三步向导，高级配置折叠；未连接状态保留首页和明确的连接、模型配置引导。
- AI 面板在窄窗口下自动收起，用户主动打开后保持可见；低高度窗口压缩状态区，为聊天记录和输入框保留空间。
- 发布资产继续同时提供独立安装包、便携包、增量更新元数据、校验文件和国内更新源清单；每个版本单独保留，不覆盖历史版本。
- 扩充发布前门禁，覆盖单元测试、关键界面矩阵、真实服务器 SSH/SFTP、Agent 只读、安全回滚、重复启动和打包运行验证。
