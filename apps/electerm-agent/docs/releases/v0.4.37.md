# ShellPilot v0.4.37

## [新增]

- 新增设置中心冷打开、连续热打开、稳定帧与 Long Task 性能门禁，持续防止客户端交互速度回退。

## [修复]

- 修复设置中心首次打开一次性渲染全部控件造成的明显卡顿。
- 修复设置中心关闭后重新打开时整棵界面重新布局造成的偶发延迟。
- 修复常驻设置抽屉关闭后仍可能被浏览器聚焦的问题，关闭态会同时隔离指针、键盘与辅助技术访问。
- 修复轻量设置页签缺少显式页签面板关联的问题，保留完整键盘导航和焦点反馈。
- 修复设置页签内容区滚动容器失效，导致屏外区块不能可靠按需加载的问题。

## [改动]

- 设置区块改为视口驱动按需挂载，首屏次要控件在空闲时加载，并使用稳定占位减少布局跳动。
- 设置页签、搜索、语言与常规数值输入改用更轻量的原生控件；已加载设置界面在当前客户端会话内复用，开关抽屉时不再重复对比整棵内容树。
- 快捷键冲突表改为进入编辑时再计算，减少普通设置渲染的同步工作。
