# ShellPilot v0.4.31

## [新增]

- Agent 取消操作默认启用 30 秒本地确认时限；后端、远程工具或诊断流未在时限内确认停止时，会明确报告取消失败，避免界面与任务锁无限等待。

## [修复]

- 修复后端取消首次未确认后，后续点击取消仍复用失败结果、无法真正重试的问题。
- 修复远程工具取消句柄与旧版 `cancelActiveTool` 兼容句柄在停止成功前被提前移除，导致再次取消可能“假成功”的问题。
- 修复诊断流延迟创建后的停止失败被静默忽略，以及取消超时被错误归类为模型故障的问题。

## [改动]

- 成功取消继续保持幂等，并发取消继续合并为同一次请求；仅失败的取消尝试会释放重试入口。
- 保持现有 Agent、AI 配置、工具调用、SSH/SFTP 和安全确认协议兼容；保护默认生效，无需迁移或手动开关。
