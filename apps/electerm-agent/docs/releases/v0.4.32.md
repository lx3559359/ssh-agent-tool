# ShellPilot v0.4.32

## [新增]

- 新增“冰川冷银”浅色主题并作为新安装默认主题，同时提供配套的“石墨冷银”深色模式；顶部品牌栏统一为连续蓝紫色带，外层面板统一为柔和冷银卡片。

## [修复]

- 修复服务器状态窗口关闭时只读诊断目标为空，导致服务器状态模块进入加载失败提示、无法打开弹窗的问题。
- 修复极窄窗口和高缩放场景下，AI 面板与设置主题中心可能裁切关键输入区或操作入口的问题。

## [改动]

- 设置、弹窗、AI 面板、帮助与更新、连接管理、运维工作区、组件和远程客户端外层界面统一采用语义化银色表面体系。
- 终端、SFTP 行、表格、日志、历史记录、任务输出、代码和差异内容继续保持紧凑扁平，不增加卡片阴影。
- 保留原有五套内置 UI 主题、自定义主题和终端配色；已有用户的主题选择不被覆盖，客户端布局、功能位置与工作流程保持不变。
