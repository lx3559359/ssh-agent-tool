# ShellPilot v0.4.27

## [新增]

- 新增覆盖 14 类主界面与二级界面的无障碍语义：顶栏与窗口控制具有可读名称，弹窗具有对话框语义、键盘焦点圈定与关闭后焦点恢复，连接、传输、任务和更新反馈可被辅助技术识别。
- 新增 SFTP 文件行键盘导航、选择和操作语义，并补充危险操作、禁用状态、紧凑窗口及中英文界面的自动验收矩阵。
- 新增真实 VPS 受保护验收：测试前后核对 x-ui、运行服务、监听端口、容器和关键文件摘要，远端写入只发生在随机 `/tmp/.shellpilot-e2e-*` 沙箱。

## [修复]

- 修复开发模式浏览器加载快速连接解析器时因 CommonJS 默认导入不兼容而出现白屏的问题。
- 修复慢速 SFTP 服务器后台刷新时，“新建文件/文件夹”输入行可能突然消失的问题；未提交草稿会保留，提交或取消后的条目不会残留。
- 修复设置、快速连接、SFTP、AI 和工具弹窗在 Esc、Tab、关闭及重开时的焦点与状态不一致问题。
- 修复窄窗口、缩放、长文本和工具卡片场景中的重叠、截断、不可滚动目标与状态文案不清问题。

## [改动]

- 统一连接、终端、SFTP、AI、运维、安全中心、帮助、设置和更新中心的层级、状态色、焦点样式、按钮名称与中英文说明；终端字符画布、业务流程、快捷键顺序和安全确认边界保持不变。
- 完成三轮最新版自检：3139 项单元测试中 3133 项通过、0 失败、6 项按环境跳过；集成桌面矩阵 20/20、真实 VPS 外部套件 5/5、质量/恢复 2/2、性能 1/1、隧道契约 51/51 与桌面 1/1 均通过。
- 重新核对 166 项既有要求：163 项已满足、2 项部分满足、1 项已由批准的新契约替代、0 项未满足、0 项未验证。`TUN-06` 仍需专用禁转发 SSH 端点，`REL-13` 仍需独立正式官网部署。
- 外部验收未修改或重启 x-ui、sshd、防火墙、容器、数据库、业务目录或其他已安装服务；继续保留 v0.4.26 及更早版本的独立发布资产。
