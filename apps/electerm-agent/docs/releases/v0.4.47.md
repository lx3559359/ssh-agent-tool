# ShellPilot v0.4.47

## [新增]

- 受管 PTY 自动命令的终端隐藏现在跟随整次提交生命周期，不再受固定五秒窗口限制。

## [修复]

- 修复慢速 SSH 连接或较长的 root/SFTP 内部命令执行超过五秒时，终端可能突然显示大段 `SHELLPILOT_*` / `__sp_*` 脚本的问题。
- 修复取消、断开连接或关闭终端时，受管命令隐藏状态可能残留的问题。

## [改动]

- 只有当前会话 nonce 认证的 `OSC 633;E` 边界才能正常结束隐藏；异常结束由控制器显式清理，并在发送 Ctrl+C 前先恢复终端输出。
- 真实 SSH 回归测试现在保留远端命令回显，持续验证客户端本身不会泄漏内部脚本。
