# ShellPilot v0.4.19

## [新增]

- 新增本地故障档案闭环：支持创建、搜索、筛选、收藏、标签、备注和状态流转，并要求完成验证后才能标记为已解决。
- 新增故障档案工作区、首页入口和侧栏入口，可集中查看诊断摘要、关联服务器、处理过程与验证结论。
- 新增故障档案 SQLite 备份、恢复和存储中心，恢复前自动保留当前数据库副本。

## [修复]

- 修复日期范围筛选的时间边界问题，避免结束日期当天的档案被遗漏。
- 修复编辑备注时可能覆盖当前活动档案的问题。
- 修复故障档案工作区层级、日间与夜间主题细节及部分中文本地化遗漏。
- 修复备份恢复占位文本和故障档案中文门禁测试问题。

## [改动]

- 故障档案默认仅保存在本机，保存前会移除密码、私钥、API Key、令牌、Cookie 和认证头等敏感字段。
- 故障档案只引用服务器标识与地址，不复制连接凭据；工作区打开和关闭不会破坏现有 SSH 会话。
- 本版本继续保留所有历史发布版本；GitHub 与魔塔更新源使用同一组校验过的 Windows 资产。
