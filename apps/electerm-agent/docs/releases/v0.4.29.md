# ShellPilot v0.4.29

## [新增]

- 新增 AI 助手图片附件缩略图预览；本地 PNG、JPEG、WebP 和 GIF 图片会直接显示在输入框内，并继续支持选择、粘贴和拖放上传。
- 新增文档与网页附件卡片，显示文件类型、大小和独立删除按钮；图片与普通文件可在窄侧栏中并排或自动换行。

## [修复]

- 修复图片上传后只能显示文件名、无法像现代 AI 对话工具一样确认图片内容的问题。
- 修复附件删除操作语义不完整的问题；删除按钮现在具有可访问名称，图片预览资源会在替换或移除后及时释放。

## [改动]

- 附件队列并入 AI 输入框表面，统一边框、焦点和响应式布局，同时保持本地文件、SFTP、网页读取及发送流程不变。
- 图片预览采用安全 MIME 白名单；SVG 或 MIME 与扩展名冲突的文件继续按普通文件卡片处理，不直接渲染。
- 发布前自检覆盖 3199 项单元测试、完整 Lint、生产构建、Windows 目录包和附件上传 Electron E2E；实机视觉检查覆盖图片与 JSON 文档混合附件状态。
