# ShellPilot v0.4.23

## [新增]

- 故障档案导出入口现在可以直接选择 Markdown、HTML 或 JSON，工作区和详情页保持一致。
- 新增一键生成 Windows 本地可运行目录的打包命令，并在缺少打包产物时给出准确操作提示。

## [修复]

- 修复浏览器上传、粘贴或拖放的本地文件没有磁盘路径时无法加入 AI 请求的问题。
- 修复不支持的图片 MIME 可能仅凭文件扩展名绕过校验的问题。
- 修复高压缩比 Office 文档在解析前缺少条目数与声明解压总量限制的问题。
- 修复超出大小上限的故障档案 JSON 或 HTML 可能被直接截断，导致文件无法解析或标签不闭合的问题。
- 修复部分 AI 自动化测试可能操作旧终端标签或继承外部模型配置的问题，提高配置、聊天、解释和语言流程的稳定性。

## [改动]

- 更新 ExcelJS 相关传递依赖的兼容维护版本，并通过普通及流式 XLSX 读写回归。
- 完成 AI 配置、对话、附件、多模态、Agent、Skill、CLI、真实 SSH/SFTP、质量、性能和 Windows 打包的分层回归。
- 保留 `v0.4.22` 及更早版本的全部发布资产；本次更新仅新增 `v0.4.23`，不会覆盖历史版本。
