# ShellPilot v0.4.51

> 稳定版发布安全与 SFTP 操作性能加固版本。

## [新增]

- 新增稳定版 Windows Authenticode 前置门禁：签名凭据缺失时停止构建，安装包或主程序签名不是 `Valid` 时停止准备和上传发布资产。
- 新增 Ubuntu/UID 0 特权文件协议 CI 门禁，单独覆盖 Windows 环境无法执行的 Linux 文件系统安全语义。

## [修复]

- 修复快速连续 SFTP 操作可能并发争用受控 PTY、旧能力结果越过当前生命周期，以及 root 文件租约释放前后顺序不稳定的问题。
- 修复终端或 SSH/SFTP 分栏尺寸变化时，隐藏终端仍触发适配、空输入锚点漂移或密码提示期间错误重锚的问题；命令跟踪准备超时也不再破坏已建立的 Shell Integration 状态。
- 修复 SFTP 恢复、终端传输和在线更新的部分运行时提示未随中英文界面切换的问题。
- 修复 Yarn 自动清理返回非零、抛出异常或返回格式异常时，打包准备仍可能继续的问题。

## [改动]

- Electron 精确锁定到经复核的 `41.10.7`，锁文件中的 `qs` 保持在兼容的安全 6.x 基线。
- 原生 SFTP 文件摘要改为服务器端单次流式读取，并加入取消、普通文件、大小一致性和 1 TiB 上限校验；root 特权文件后端继续沿用原有摘要路径。
- 安全删除确认阶段并发执行只读的快照与源文件复核；只有两项都通过后才允许远端变更，并保持原有错误优先级、回滚和恢复记录语义。
