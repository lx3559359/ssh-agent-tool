# ShellPilot v0.4.17

## [新增]

- 增加 SSH 隧道本机端口冲突预检，并提供可用端口建议，不会自动修改已保存配置或擅自启动隧道。
- 增加 AI 修改 SFTP 文本文件前的差异预览，可确认写入、取消修改，并在写入后从安全操作中心恢复原文件。
- 增加 SFTP 目录批量传输结果汇总，保留每个文件的成功、失败和重试信息。

## [修复]

- 修复 SSH 隧道自动启动阻塞终端就绪、重连后遗留旧运行状态，以及端口占用时错误不清晰的问题。
- 修复 SFTP 上传失败时可能截断或留下半个目标文件的问题；上传改为同目录临时文件写入完成后再提交。
- 修复目录批量上传中单个文件失败导致其他结果丢失，以及进度可能重复累计的问题。
- 修复隧道端口冲突提示缺少英文文案导致国际化一致性检查失败的问题。

## [改动]

- SFTP 网络失败重试明确标注为“从头重试”，保留上次已传字节作为诊断信息，不再伪装成断点续传。
- SFTP 覆盖上传优先采用服务器声明支持的原子重命名能力，不支持时回退到标准 SFTP 重命名流程。
- 所有新增可靠性能力继续复用现有 SSH、SFTP、安全备份和回滚链路，不改变普通终端输入方式。
