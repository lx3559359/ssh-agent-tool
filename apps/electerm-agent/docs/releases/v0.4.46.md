# ShellPilot v0.4.46

## [新增]

- 新增受管 PTY 自动命令的可见终端回显保护；SFTP 与 root 文件能力探测继续使用当前交互式 Shell 身份，但不再把内部实现脚本展示给用户。

## [修复]

- 修复打开或恢复 SFTP 面板、探测 root 文件能力时，远端 TTY 会把 `SHELLPILOT_FILE` / `__sp_*` 受管 PTY 内部脚本完整回显到可见终端的问题。
- 修复受管命令的 Shell 生命周期标记被 SSH/WebSocket 拆分到多个数据块时，回显抑制可能无法及时解除并导致文件操作超时的问题。
- 修复错误会话或过期 OSC 633 标记可能提前解除受管命令回显抑制的问题；释放边界现在绑定当前命令追踪会话 nonce。

## [改动]

- 受管 PTY 自动命令只在收到当前会话认证的 `OSC 633;E` 命令标记后恢复终端输出，并从该边界继续传递完整的 E → C → D → A/B 生命周期和文件协议数据。
- 跨数据块检测采用有界滚动扫描，不缓存整条内部命令；超时或同步发送失败时会恢复终端，普通输入、密码处理、用户命令和 root 文件协议保持原有行为。
