# ShellPilot v0.4.38

## [新增]

- SFTP 文件管理器底部新增当前标签页的上传、下载进度条，显示百分比、已传输字节、总量和实时速度。
- 进度条支持展开任务详情，并复用现有暂停、恢复和取消控制；快速完成或失败的任务会短暂保留结果状态。

## [修复]

- 修复 SFTP 安全复制与远程编辑保存时重复执行无效 `chown`、`chmod`，在服务器拒绝冗余元数据写入时误报 `Permission denied` 的问题。
- 修复使用 `root` 登录仍保存失败时提示不清晰的问题；现在会标明实际 SFTP 身份与失败阶段，并提示检查只读文件系统、ACL/SELinux、不可变属性、chroot 或 SFTP 服务限制。
- 修复远程编辑保存失败后关闭内容、无法直接修正权限重试的问题；编辑内容会保留。
- 修复传输历史较多时最新完成状态可能丢失，以及带错误信息的旧运行状态未正确显示为失败的问题。

## [改动]

- SFTP 进度更新按 100 毫秒合并显示，并限制终态历史扫描范围，避免进度展示增加高频渲染开销。
- 真实属主或权限不一致时仍会执行严格写入与最终校验，不降低安全事务的失败阻断要求。
- 增加仅使用本机 `127.0.0.1` 的上传、下载进度端到端验证，并校验传输前后 SHA-256 一致性。
