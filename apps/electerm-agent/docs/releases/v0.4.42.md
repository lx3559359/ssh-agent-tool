# ShellPilot v0.4.42

## [新增]

- SFTP 文件区底部新增醒目的上传、下载进度坞，实时显示方向、文件名、百分比、已传输大小、总大小和速度。
- SFTP 右键菜单将“安全删除（可恢复）”与“快速删除（不可恢复）”作为直接操作展示，并将低频功能收纳到“备份与恢复”和“更多操作”子菜单。
- SSH 主机指纹确认新增连接目标、密钥类型、指纹和 `known_hosts` 路径的结构化展示及复制按钮。

## [修复]

- 修复上传或下载结束后进度反馈消失过快、失败原因不明显的问题；现在会保留完成、部分完成或失败结果，直到用户关闭。
- 修复文件夹上传包含被占用文件时仍可能显示“传输完成”的问题；现在会准确汇总成功与跳过数量。
- 修复传输失败详情重复显示完整本地路径的问题，错误信息会保留可操作原因并隐藏本地路径。

## [改动]

- 安全删除现在会立即显示“正在创建并验证恢复快照”，准备完成后才允许确认；失败时可直接重试。
- 快速删除确认框强化不可恢复风险提示，并显示有限的目标预览和剩余数量。
- SSH 主机指纹变化时使用高风险警告样式，默认焦点停留在“拒绝连接”，降低误确认风险。
- SFTP 文件行支持 `Shift+F10` 打开上下文菜单，并在关闭菜单后恢复键盘焦点。
