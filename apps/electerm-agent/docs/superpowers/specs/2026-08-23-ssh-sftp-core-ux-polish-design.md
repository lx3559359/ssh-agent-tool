# SSH + SFTP 核心体验稳健精修设计

日期：2026-08-23  
状态：已获用户确认  
方案：A「稳健精修」

## 1. 背景

ShellPilot v0.4.41 已具备 SSH 快速连接、主机指纹确认、终端、SFTP 双栏浏览、上传下载进度、安全删除、快速删除和恢复能力。本轮在隔离的本地 SSH/SFTP 环境中完成了当前版本审计：

- SSH 连接、终端命令与 SFTP 浏览可正常完成。
- 上传、下载、锁定文件跳过、快速删除、安全删除与恢复均通过现有核心 E2E 回归。
- 当前最明显的体验问题是终态表达矛盾、SFTP 右键菜单过长、安全删除开始阶段缺少即时反馈，以及主机指纹长信息不便核验。

基线验证结果：

- 审计截图流程：1/1 通过，覆盖 10 个关键界面状态。
- 键盘与可访问性检查：1/1 通过。
- `test/e2e/027.quality-core-flows.spec.js`：1/1 通过，耗时约 27.5 秒。

## 2. 目标

1. 让上传、下载、跳过和失败状态在明显位置持续、准确地呈现。
2. 保持安全删除与快速删除为直接入口，同时降低右键菜单扫描成本。
3. 让安全删除在快照准备阶段立即提供可见反馈，并减少不必要的等待。
4. 提升主机指纹确认的信息可读性、可复制性和安全焦点行为。
5. 补齐高频流程的键盘操作、屏幕阅读器提示与自动化回归。

## 3. 非目标与安全边界

本轮不修改：

- SSH/SFTP 协议实现、认证流程或服务器信任规则。
- 上传下载传输引擎、文件内容或目标路径语义。
- 安全删除的恢复快照、验证、确认和事务记录要求。
- 快速删除的目标校验、事务目录保护和最终确认。
- 快速连接的三步顺序、既有功能入口或默认工作流。
- AI 面板、服务器管理及其他非 SSH/SFTP 核心页面。

任何性能优化都只能移除重复查询、重复渲染或可安全并行的等待，不能跳过安全检查。

## 4. 设计原则

- **先说明状态，再显示数字。** 用户应先知道任务正在运行、已暂停、部分完成或失败，再阅读百分比和速度。
- **运行进度与任务结果分离。** “总量计算中”只属于运行阶段，不能出现在完成状态。
- **直接操作保持直接。** 安全删除和快速删除继续位于一级菜单。
- **危险程度可视化区分。** 可恢复操作使用警示色，不可恢复操作使用危险色。
- **安全等待必须可见。** 安全删除快照准备不能表现为无响应。
- **保留单一事实来源。** 界面从现有 `fileTransfers`、`transferHistory` 和安全事务状态派生，不创建第二套传输或安全状态。

## 5. 传输进度坞

### 5.1 状态模型

进度摘要统一为以下公开状态：

| 状态 | 视觉 | 摘要规则 | 保留策略 |
| --- | --- | --- | --- |
| 排队/统计中 | 主色、动态进度 | `正在准备上传` 或 `正在统计文件 · 已传 X`，不显示百分比 | 直到进入可计算或终态 |
| 传输中 | 主色、确定进度 | `上传中 · 62% · 20.8 MB / 33.6 MB · 6.3 MB/s` | 任务运行期间 |
| 暂停/中断 | 橙色 | `上传已暂停` 或 `连接中断`，保留已传字节 | 直到恢复、失败或取消 |
| 完全成功 | 绿色 | `上传完成 · 成功 N 项`，确定总量时显示 100% | 8 秒或用户关闭 |
| 部分完成 | 橙色 | `上传结束 · 成功 N 项 · 跳过 M 项` | 直到用户关闭或下一任务替换 |
| 失败 | 红色 | `上传失败 · 失败 N 项` | 直到用户关闭或下一任务替换 |

“部分完成”必须是独立终态，不能复用绿色 `completed` 外观。

### 5.2 字节和百分比规则

- 仅当所有活动项都有正数总量时显示百分比。
- 未知总量时显示“正在统计文件”和已传字节，不显示 `/ 0 B`。
- 完全成功时才可以强制显示 100%。
- 存在跳过项时不把传输字节伪装为完整总量；终态改为结果摘要。
- 速度只在大于零且任务运行时显示。

### 5.3 交互

- 任务创建后进度坞立即出现，发布节流仍保持约 100 ms，避免高频重绘。
- 运行时按钮为“展开详情/收起详情”。
- 终态按钮统一为“查看详情”，另提供可访问名称明确的关闭按钮。
- 详情行显示方向、源、目标、已传字节、状态和原因。
- 锁定文件显示“已跳过：文件正在被其他程序占用。关闭占用后可重新上传。”
- 继续禁止逐文件 EBUSY 错误通知；顶部只显示一次聚合结果。

### 5.4 可访问性

- 进度条保留 `role="progressbar"`；未知总量时不提供 `aria-valuenow`。
- 终态摘要使用 `role="status"`、`aria-live="polite"` 和 `aria-atomic="true"`。
- 不播报每一个百分比更新，只播报阶段变化和终态。

## 6. SFTP 上下文菜单

### 6.1 一级菜单

根据本地/远程、文件/目录和多选状态动态显示，顺序为：

1. 进入、上传/下载、在终端访问目录等当前对象的直接动作。
2. AI 文件分析或编辑等对象级动作。
3. 分隔线。
4. `安全删除（可恢复）`：橙色盾牌语义。
5. `快速删除（不可恢复）`：红色垃圾桶语义。
6. 分隔线。
7. 重命名、复制文件路径。
8. `备份与恢复` 子菜单。
9. `更多操作` 子菜单。

快速删除仍保持“一次右键 + 一次确认”，不增加额外层级。

### 6.2 子菜单

`备份与恢复` 包含：

- 一键备份。
- 恢复最近备份。
- 安全操作中心。

`更多操作` 包含适用的现有入口：

- 复制、剪切、粘贴。
- 新建文件、新建文件夹。
- 全选、刷新。
- 编辑权限、文件信息。
- 其他平台或文件类型特有的低频动作。

所有现有动作继续存在；只调整信息层级和分组。

### 6.3 键盘

- 当前 roving-tabindex 和上下箭头导航继续保留。
- 聚焦文件行时，`Shift+F10` 或 Context Menu 键打开相同菜单。
- 菜单打开后聚焦首个可用项；`Esc` 关闭并恢复到原文件行。
- 不新增 Delete 或 Shift+Delete 快捷键，避免误触不可恢复操作。

## 7. 删除体验

### 7.1 快速删除

- 确认框显示不可恢复徽标、目标数量和最多三个目标名称；更多目标显示剩余数量。
- 正文明确“不会创建恢复快照，无法从安全操作中心恢复”。
- 主按钮继续为红色“永久删除”。
- 初始焦点放在“取消”，Enter 不得在未移动焦点时直接触发永久删除。
- 删除成功、部分失败和状态不确定继续使用现有刷新后状态规则。

### 7.2 安全删除

点击菜单项后立即显示阶段式窗口：

1. `正在准备恢复快照`：显示目标与进度提示，删除按钮禁用，可取消。
2. `恢复快照已验证`：展示快照摘要并启用“安全删除”。
3. `正在删除`：防止重复提交。
4. 成功关闭窗口并刷新列表；失败保留目标和原因，允许重试。

允许的性能改进：

- 合并同一目标的重复 `stat`、列表刷新或恢复记录查询。
- 将互不依赖的只读预检并行执行。
- 缓存本次确认周期内已经验证的快照结果。

不允许：

- 先删除再补快照。
- 未验证快照就启用确认。
- 因性能原因绕过安全事务中心记录。

## 8. SSH 主机指纹确认

### 8.1 数据契约

主机指纹提示在保留现有 `instructions` 和 `confirmResult` 的基础上，增加可选结构化信息：

- `target`
- `keyType`
- `fingerprint`
- `knownHostsPath`
- `hostKeyChanged`

旧客户端或缺少结构化字段时继续使用现有文本提示，保证兼容。

### 8.2 界面

- 目标、密钥类型、指纹和 `known_hosts` 路径分行呈现。
- 指纹使用等宽字体，并提供“复制指纹”。
- 路径允许自动换行，并提供“复制路径”。
- 首次连接使用普通确认样式。
- 指纹变化使用危险标题和警告说明，但不弱化现有中间人攻击提示。
- 按钮放入标准页脚：左侧“拒绝连接”，右侧“信任并保存”或“更新指纹”。
- 初始焦点放在“拒绝连接”；关闭和 Escape 等同拒绝。

展示层不得直接修改传输结果或伪造完成状态。

## 10. 错误处理

- 单个锁定文件：标记跳过，聚合一次提示，不弹重复错误。
- 全部失败：红色失败终态，详情列出失败原因。
- 部分成功：橙色部分完成终态，成功文件保持有效。
- 安全快照失败：禁止删除，保留目标并提供重试。
- 快速删除远端状态不确定：刷新后展示现有“不确定，请以列表为准”提示。
- 连接中断：进度坞保留已传字节，交由现有恢复/重试机制处理。

## 11. 测试策略

### 11.1 单元测试

- 传输状态：未知总量、确定总量、完全成功、跳过、部分成功、失败、终态保留。
- 菜单：本地/远程、文件/目录、多选、窗口溢出、两个子菜单和全部入口保留。
- 安全删除：即时打开、快照未验证时禁用、成功解锁、失败可重试。
- 主机指纹：结构化字段、文本回退、指纹变化、复制内容和安全默认焦点。
- 中英文文案契约。

### 11.2 E2E

- 快速连接、主机指纹确认和终端命令。
- SFTP 浏览、键盘打开菜单、Escape 恢复焦点。
- 上传和下载可见进度。
- Windows 锁定文件上传显示部分完成，不出现 EBUSY 错误风暴。
- 快速删除保持单次确认并永久删除。
- 安全删除窗口立即出现，快照验证后才能删除，安全中心可恢复。

### 11.3 回归

- 运行现有 SSH/SFTP 核心质量 E2E。
- 运行相关 SFTP、主机指纹、模态框和翻译单元测试。
- 在打包版本中重新截图检查正常、部分完成和危险确认状态。

## 12. 验收标准

1. 任一上传或下载任务创建后，用户无需打开其他页面即可看到进度。
2. 完成状态中不再出现“总量计算中”或 `/ 0 B`。
3. 锁定文件场景显示“成功 N、跳过 M”，且没有重复 EBUSY 通知。
4. 远程文件或目录右键菜单中可直接看到安全删除与快速删除。
5. 快速删除保持一次确认，且确认内容清楚表达不可恢复。
6. 安全删除点击后立即显示准备状态，快照验证前不能删除。
7. 主机指纹和 `known_hosts` 路径完整可读并可复制。
8. 键盘可完成文件行导航、打开菜单、关闭菜单和恢复焦点。
9. 所有现有安全门槛、功能入口和核心 E2E 继续通过。
