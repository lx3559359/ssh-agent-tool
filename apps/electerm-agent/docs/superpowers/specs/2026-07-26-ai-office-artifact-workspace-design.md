# ShellPilot AI 运维办公成果物工作区设计

## 目标

在不改变 SSH 终端、SFTP 和在线更新核心行为的前提下，把 ShellPilot AI 助手从以聊天文本为主的工具升级为能够生成、预览、轻量编辑、保存和交付运维办公成果的工作区。

第一阶段聚焦以下成果：

- 运维诊断报告
- 服务器巡检报告
- 服务器资产与服务清单
- 变更实施记录
- 安全检查报告
- 故障复盘报告
- 自定义运维文档和表格

支持 DOCX、XLSX、PDF、Markdown 和 CSV。生成能力必须随 Windows 客户端一起打包，不要求目标电脑安装 Office、WPS、Python 或其他运行环境。

## 非目标

- 不在客户端内实现完整的 Word 或 Excel 编辑器。
- 不重写现有 AI 对话、SSH 终端、SFTP 或安全操作中心。
- 不允许模型直接生成二进制文件或执行本地代码来转换格式。
- 不在普通 SSH 启动阶段加载文档生成和预览模块。
- 不自动上传成果到服务器，也不静默覆盖已有文件。

## 总体架构

成果物能力由五个边界清晰的模块组成。

### 成果物调度器

接收 AI 返回的结构化成果描述，校验成果类型、标题、章节、表格、内容大小和文件数量。无效数据不得进入格式生成器，并应返回可读的修复提示。

调度器不接受模型提供的本地执行命令、任意磁盘路径或二进制内容。

### 格式生成器

格式生成器采用可注册的处理器接口。每个处理器独立实现数据验证、文件生成、预览数据和导出能力。

首批处理器：

- `document`：DOCX
- `spreadsheet`：XLSX 和 CSV
- `report`：PDF 和 Markdown

后续新增格式时只注册新处理器，不修改 AI 对话和 SSH 核心。

### 成果物存储

每项成果保存以下元数据：

- 成果 ID、类型、标题和版本
- 创建时间和更新时间
- 来源对话、任务和服务器
- 结构化源数据
- 已生成文件及校验摘要
- 上传记录和本地保存记录
- 脱敏状态

默认保存在 ShellPilot 独立成果目录。成果历史与聊天消息分离，删除聊天记录不会静默删除用户已经保存的文件。

### 成果预览与轻量编辑

成果在中间工作区以独立标签页打开，不挤占右侧 AI 对话区域。

支持：

- 修改标题、副标题、摘要、段落和章节顺序
- 增删报告章节
- 修改表格单元格、列名、排序和筛选
- 修改页眉、页脚、服务器名称和报告日期
- 撤销、重做和自动保存草稿
- 重新生成当前格式
- 查看和恢复历史版本

复杂排版由用户通过 Word、WPS、Excel 或 LibreOffice 继续编辑。

### 成果物操作网关

统一处理以下操作：

- 保存和另存为
- 打开成果所在目录
- 使用系统关联应用打开
- 上传到当前 SFTP 目录
- 从诊断任务、服务器状态、安全操作记录生成成果

操作网关必须复用现有文件选择、SFTP、安全确认、审计和取消机制。

## AI 数据协议

AI 不直接返回 DOCX、XLSX 或 PDF 文件。AI 通过受约束的成果工具返回结构化数据，例如：

```json
{
  "type": "diagnostic-report",
  "title": "生产服务器故障诊断报告",
  "server": "prod-web-01",
  "summary": "",
  "sections": [],
  "tables": [],
  "risks": [],
  "recommendations": []
}
```

客户端校验结构化数据后再生成文件。同一份源数据可以生成 DOCX、PDF 和 Markdown，避免不同格式出现内容不一致。

成果工具至少包括：

- `create_artifact`
- `update_artifact`
- `regenerate_artifact`
- `export_artifact`
- `upload_artifact_to_sftp`

这些工具只负责成果生命周期，不允许绕过既有 Agent 工具网关执行 SSH 命令。

## 用户交互

### AI 对话

输入框工具栏增加“生成成果”入口，提供：

- 运维诊断报告
- 服务器巡检报告
- 资产清单
- 变更记录
- 故障复盘
- 自定义文档
- 自定义表格

用户也可以直接用自然语言要求生成成果。

生成完成后，聊天中只显示紧凑成果卡片：

- 标题
- 格式和页数或表格数量
- 生成状态
- 预览、保存、上传和更多操作

长文档正文不直接展开在聊天记录中。

### 成果预览

成果预览标签页包含：

- 左侧：文档大纲、工作表或历史版本
- 中间：分页文档或虚拟化表格
- 顶部：保存、另存为、重新生成、外部打开、上传 SFTP
- 可选 AI 修改入口：用自然语言修改当前成果

### 成果中心

左侧导航增加“成果”入口，支持：

- 最近生成
- 诊断报告
- 巡检报告
- 表格与清单
- 草稿
- 已上传到服务器
- 已删除

支持按服务器、格式、日期和任务搜索。

未配置模型 API 时，成果中心允许浏览历史成果，但生成入口显示明确的模型配置引导。

## 格式能力

### DOCX

- 封面、摘要、目录和分级章节
- 正文、代码块、命令输出和提示框
- 表格、分页、页眉、页脚和页码
- 风险等级和状态颜色
- 中文字体和中英文混排

### XLSX

- 多工作表
- 表头冻结、筛选和排序
- 自动列宽和字段类型
- 状态、风险和资源占用条件着色
- 汇总工作表

### PDF

- 可复制文字
- 中文字体
- 正确分页和页码
- 目录
- 表格跨页
- 适合打印和归档

PDF 必须从经过校验的报告模型生成，不使用整页截图拼接。

### Markdown 和 CSV

Markdown 作为可继续交给 AI 修改的开放文档格式。CSV 作为表格交换格式。DOCX、XLSX 和 PDF 均保留对应结构化源数据。

## 数据来源

用户明确引用后，成果可以使用：

- 当前对话
- 当前 SSH 终端的选定输出
- 只读诊断任务结果
- 服务器状态中心数据
- 用户选中的 SFTP 文件
- 安全操作中心的变更、备份和回滚记录
- 多服务器批量检查结果

大日志和文件继续使用分段读取和摘要，不把完整大文件一次发送给模型。

## 权限与安全

无需确认：

- 生成、预览和修改本地成果草稿
- 读取 SSH 状态、日志和配置
- 查询服务、端口、进程、磁盘和网络
- 保存到用户通过系统文件选择器明确选择的新路径

需要确认：

- 覆盖已有本地文件
- 上传或覆盖远程 SFTP 文件
- AI 修改服务器文件
- 执行服务重启、防火墙、软件安装等远程变更

高风险远程变更继续复用现有备份、验证、审计和快捷回滚流程。

生成前自动识别并遮盖 SSH 密码、私钥、API Key、Token、Cookie、数据库密码和用户配置的敏感字段。预览中标明已脱敏，恢复敏感字段必须由用户主动操作。

## 错误与恢复

成果任务状态统一为：

- 正在整理数据
- 正在生成文档
- 正在生成预览
- 已完成
- 已取消
- 生成失败，可重试

生成失败时保留结构化草稿和已完成版本。按需模块加载失败时显示“重新加载文档模块”，不让客户端白屏。更新后旧缓存导致模块找不到时，沿用现有分包异常恢复机制。

## 性能边界

- 普通 SSH 启动不加载 DOCX、XLSX、PDF 模块。
- 打开成果中心或生成成果时才按需加载。
- 单项成果默认上限为 20 MB。
- 表格预览采用虚拟滚动。
- 文档采用分页渲染。
- 后台生成可取消，不占用终端输入。
- 生成器不得阻塞 Electron 主进程。

## 分阶段交付

### 第一阶段：成果基础设施

- 成果数据协议、调度器、存储和版本
- Markdown、CSV 和结构化预览
- 聊天成果卡片
- 成果中心和独立预览标签页
- 保存、另存为和打开目录

### 第二阶段：办公格式

- DOCX 生成和分页预览
- XLSX 生成和虚拟化表格预览
- PDF 生成和打印预览
- 首批运维报告与清单模板

### 第三阶段：AI 与运维联动

- AI 创建、更新和重新生成成果
- 从诊断、状态中心和安全操作记录生成报告
- 自然语言轻量修改
- 上传到当前 SFTP 目录
- 批量服务器巡检成果

## 验收标准

- 生成的 DOCX、XLSX 和 PDF 能在常见 Windows 应用中正常打开。
- 中文字体、分页、表格结构、页眉和页脚正确。
- 同一结构化成果生成的多种格式内容一致。
- 成果生成、预览和保存不影响 SSH 输入、快捷键和 SFTP。
- 取消、超时、失败重试和草稿恢复可用。
- 敏感信息在预览、文件和日志中均不会意外泄漏。
- SFTP 上传和覆盖遵守现有安全确认。
- 1366×768、1920×1080、Windows 125% 和 150% 缩放下布局可用。
- 日间和夜间主题下文字、状态和操作按钮清晰可读。
- 文档模块加载失败不会造成主界面白屏。
- SSH、SFTP、AI 对话、安全中心和在线更新原有回归测试继续通过。
