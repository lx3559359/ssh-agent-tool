# ShellPilot 发布安全与运维工作区生命周期设计

## 目标

- AI 与 Agent 的停止按钮必须同时中止网络请求和响应流。
- 运维工具由用户从顶部入口打开，并且只能由用户点击关闭按钮退出。
- 删除面向用户的 Electerm 云同步地址和旧更新地址。
- 修复真实服务器连续回归、视觉回归和性能门禁的可信度。

## 设计

### AI 请求生命周期

流式请求创建后，请求控制器保持登记到流结束、失败或主动停止。流会话保存
`requestId` 与控制器；停止流时先调用控制器的 `abort()`，再销毁响应流并清理映射。
非流式请求仍在请求函数结束时清理控制器。

### 运维工作区

顶部“运维工具”入口显式打开工作区，工作区右上角关闭按钮显式退出。移除鼠标离开
500ms 后自动关闭的历史交互。任务完成、切换运维标签、切换 SSH/SFTP 标签都不改变
工作区开关状态。

### 品牌与同步

保留 GitHub、Gitee、自定义服务和 WebDAV 同步能力，移除 Electerm 云同步选项及其
地址。旧配置中的 `cloud` 不再展示或自动连接第三方服务。所有帮助入口指向
ShellPilot 自有文档。

### 回归门禁

- 单元测试验证请求控制器的红绿生命周期。
- 单元测试验证运维面板没有自动关闭事件。
- 品牌测试扫描客户端代码，禁止 Electerm 同步和更新地址。
- 真实服务器回归在运维检查结束后显式关闭工作区，再进入 SFTP。
- 视觉回归显式建立所需页面状态，不再假定启动时自动创建本地终端。
- 性能门禁增加可配置预算，CI 超过硬阈值时失败。

## 非目标

- 本轮不拆分终端核心包。
- 没有可信代码签名证书时不伪造签名；只保留为发布前阻塞事项。
- 本轮不发布在线更新。
